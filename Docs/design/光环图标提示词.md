# 光环图标提示词（v2 · 全套 7 种）

> 日期：2026-10-31 · 状态：**已落地**（图标由 `Tools/art-audit/render_aura_icons.py` 渲染，见 §七）。
> 用途：重做 HudBuff 里那排光环指示物图标（`UiLayout.BuffIconSize = 72 px`）。
> 只生成图标本体，不生成整屏、不生成卡面、不烘焙数字。

## 一、现在为什么不合适

不是画得不好，是**这套图标根本没有自己的图形语言**，它是拿卡面的触发符号临时拼的：

1. **符号是借的。** `AuraIconData.Glyph` 去 `TriggerIconLibrary` 取 α 剑 / β 盾 / γ 感叹号，而这三个符号在卡面上的语义是「这条效果**什么时候结算**」。同一个图形背两套含义，玩家看到剑不知道是「进攻时触发」还是「进攻力量 +2」。
2. **7 种光环只有 3 个图形。** `AtkPower` 和 `QuickRefill` 都画剑；`DefPower`、`ImmuneHigh`、`ImmuneLow` 都画盾；`Combo` 画感叹号（等于 γ「特殊时机」）。也就是说，除了底色，**「快速回填」和「进攻 +2」长得一模一样**，「免疫 ≥6」和「防御 +2」只差一个底色。
3. **底色还缺一档。** `AuraIconData.PlateColor` 里 `QuickRefill` 落到 `default`，取的是 `MiniCardFace (#262F3F)` —— 那是迷你卡卡的卡片面色，不是语义色。结果它是一枚「深灰卡面色 + 白剑」的图标，和进攻光环几乎无法区分。`ImmuneHigh` / `ImmuneLow` 则共用 `AuraPlateImmune (#B98A2A)`，只靠右下角 `≥6` / `≤3` 分辨。
4. **没有轮廓记忆点。** 一枚 72 px 的纯色方块 + 44 px 白色细符号，缩到实际显示尺寸后只剩一团色块，和低多边形卡面不是一套语言。

## 二、新系统：4 条规则

**规则 1｜一枚光环 = 一枚独立徽章。** 不再用「色块 + 符号」两层拼装，改成一张整图（图标自带形状、颜色、描边），`_plate` / `_glyphA` 在代码里关掉。

**规则 2｜形状优先，颜色辅助。** 7 种各有一个不可互换的剪影，**去掉颜色也能认**；颜色只做二次确认（色弱玩家同样能读）。这条是「简洁易读」的全部含义。

**规则 3｜骨架统一：flat-top 六边形。** 上边水平、六个短边 —— 44 px 下轮廓依旧锋利，而且**不像卡牌矩形**，一眼就知道「这是附着在牌上的东西，不是一张牌」。所有 7 枚共用这一副骨架，才是「一套图标」。

**规则 4｜数字归 UI。** 右下角约 28% 见方留给代码画 `+3` / `≥6` / `≤3`。图里**绝不出现**任何数字、字母、比较符。

三个刻意的取舍：

- **攻/防二选一改成「把徽章劈成两格」。** 并排画一块剑 + 一块盾在 44 px 下就是两团白斑，读者只看到「攻防」，看不到「选一个」；现在的做法是**右半格压暗一档、中间一道接缝**，一眼看出「这一枚由两半拼成，用哪半自己挑」。
- **连击用闪电。** 连击的语义是「接着再打一次」，不是「特殊效果」；闪电（一记实心雷）在小尺寸下的剪影比三重人字更硬、更好认，也不会和任何别的图标撞。
- **免疫高 / 低共用盾，只翻三角方向。** ▲ = 挡得住更高的力量，▼ = 只挡低力量，方向本身就是记忆钩子；两枚成对出现时玩家一眼就懂。
- **`QuickRefill` 必须有自己的绿。** 冷却缩短是「循环」不是「力量」，既要换图形（↻）也要换色，否则它永远是「长得像进攻的异常图标」。

## 三、母版风格块（STYLE）

每一条提示词都拼上这一段，保证 7 枚是同一套东西。**颜色、描边、留白都在这里定死，各条的 SUBJECT 只换图形。**

```text
STYLE: flat vector game UI badge for a bright low-poly fantasy card battler. One regular flat-top hexagon badge, seen straight on, perfectly centered, no perspective. The hexagon is filled with one solid saturated family color, with a single darker facet band along the bottom 18 percent of the shape (low-poly feel, hard-edged, no gradient mesh). A thick uniform near-black outline (#20202A) of about 14 pixels on a 512 pixel cell wraps the whole hexagon. Inside sits one single near-white (#FFF6E2) symbol, bold and geometric, built from thick bars of even weight (minimum 36 pixels on a 512 pixel cell), no thin hairlines, no outline on the symbol itself. Crisp hard edges, matte flat shading, exactly two tones per shape plus the outline. The symbol sits slightly above the optical centre, leaving the bottom-right quarter of the badge clean. Generous empty margin around the badge. True transparent background.
```

- 画布：**1536 × 1024**，4 列 × 2 行，每格 384 × 512，徽章在格内居中。

## 七、落地规格（2026-10-31 已落地）

**实际做法改了：不走生图，改用脚本渲染。** 这套图标是纯几何（六边形 + 单色剪影），矢量定义一次、脚本渲染一次，八张的描边粗细 / 留白 / 倒角必然一致；生图模型每张都会把 512 网格画歪一点，切完再对不齐。上面那套 prompt 保留下来，是给「想换一种画风、要手绘质感」时用的备选路线。

**资源与命名**

```
Assets/Resources/AuraIcons/Aura_01_atk.png          256×256，Sprite
Assets/Resources/AuraIcons/Aura_02_def.png
Assets/Resources/AuraIcons/Aura_03_both.png
Assets/Resources/AuraIcons/Aura_04_combo.png
Assets/Resources/AuraIcons/Aura_05_immunehigh.png
Assets/Resources/AuraIcons/Aura_06_immunelow.png
Assets/Resources/AuraIcons/Aura_07_refill.png
Assets/Resources/AuraIcons/Aura_08_sigil.png
```

放在 `Resources/` 下是跟 `Resources/Elements/Element_0x_*.png` 同一套口径：**按名取图，不额外挂资产**。`.meta` 沿用 Element 图标的导入模板（Sprite / Single / Alpha Is Transparency / Border 0）。

**生成脚本**

```
Tools/art-audit/render_aura_icons.py     # 出 8 张 + 核对图
Captures/art-review/AuraIcons_Review.png # 144 / 72（含数值条）/ 40 px 灰阶三档核对
```

设计口径：512 号设计稿 → 4× 超采样 → LANCZOS 缩到 256；`UiLayout.BuffIconSize = 72` 显示时约 3.5 倍余量。描边 15（512 口径）≈ 2.1 px@72；符号最细笔画 ≥ 30 ≈ 4.2 px@72。六边形宽 450（88% 画布）、中心略偏上，给底部 `+A / ≥A / ≤A` 那条数值底衬让位。

> **2026-10-31 晚 · 两处回到概念板第 1 版**：盾改回**尖顶纹章盾**（apex 在上、两肩最宽，`shield_pts` 一套共用，`DefPower` / `AtkOrDefPower` / `ImmuneHigh` / `ImmuneLow` 同步）；回转箭头改回第 1 版比例（环径 0.55R、笔画 0.167R、箭头落在缺口里），比第 2 版那圈细环更「一眼看出是循环」。`Aura_02_def.png` 与 `Aura_07_refill.png` 已重出。

**代码改动**

1. 新增 `Assets/Scripts/Unity/Ui/AuraIconLibrary.cs`：`AuraKind → Resources.Load<Sprite>("AuraIcons/...")`，带缓存；**没有做成 ScriptableObject** —— 文件名与枚举一一对应且由脚本生成，再挂一层资产只多一个会忘记同步的地方。
2. `AuraIconView.Bind` 增加「整图模式」：`_plate` 直接画徽章（72×72、Simple、白乘色），`_glyphA/_glyphB` 关闭，`_dim` 关闭、改用 `UiTheme.AuraBadgeDim` 乘暗表达「本拍用不上」，`_frame` 涂成全透明 —— 它是这一层**唯一的射线目标**，`enabled = false` 会连长按/拖拽一起丢。
3. 库取不到图（素材缺失）时**自动退回 v1** 的「底版 + 符号」画法；`AuraIconData.GlyphSprite` / `IsDual` / `PlateColor` 全部保留，`HudBuffView`、`PreparedAuraView`、`AuraTooltipView` 不用改。

> 不建议的做法：直接把新图塞进 `TriggerIconLibrary` 当 glyph 用。那会把 α/β/γ 的语义再污染一遍，正是这次要修的病根。

## 八、验收清单

按顺序过，任何一条不过就退回重画：

- [ ] 缩到 **72 px** 看，7 枚不看颜色能否区分？
- [ ] **去色（灰度）**后还能区分？（形状优先原则的唯一检验）
- [ ] 贴在浅色水城背景上、和深色冷却槽上，边缘都立得住？
- [ ] 底部那条数值底衬（56×24，压在图标下沿）压上去后，六边形还看得出是六边形？
- [ ] 最细笔画 ≥ 4 px（72 尺寸）？
- [ ] 8 枚的描边粗细、留白、六边形比例看起来是同一副模子？
- [ ] 图里有没有漏出数字 / 字母 / 水印 / 棋盘格假透明？
