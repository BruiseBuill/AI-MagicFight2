# 战斗交互

> 状态：现行 · 核对日期：2026-10-30 · 范围：代码中的输入方式；本次未执行 Play 或视觉验收。

玩法见 [规则基线](../rules/01-规则基线.md)，布局见 [战斗信息布局](战斗信息布局.md)。交互只回填引擎提供的合法选项。

## 手牌与目标

| 操作 | 行为 |
|---|---|
| 进攻 / 单牌防御 | 拖动手牌，在中央合法出牌区松手提交；单击不出牌 |
| 双发防御 | 点击累计选择最多两张，再拖入出牌区提交一组合格防御牌 |
| 无效拖放 | 手牌返回；双发未凑成合法组合时保留选择，不提交 |
| 换牌 / 手牌效果目标 | 点击选择，在对应面板确认；数量限制由决策提供 |
| 冷却区目标 | 点击高亮卡牌；区域效果点击高亮的剩余冷却档 |
| 跳过 / 完成 | 右侧动作区提交当前决策的 Skip / Done；专用弹窗使用自己的确认入口 |

主动结束进攻的生命代价由引擎给出，追加连击为 0。双人选牌时可提出平局，界面显示观察进度。默认有利效果直接触发，仅目标选择或有代价的效果保留操作。

## 光环

- 双方冷却区的可用指示物逐枚显示，同类型不合并；长按查看来源和效果。对手或当前不可用的光环只可查看。
- 将己方可用图标拖入手牌区，准备对应光环；拖入手牌区不应一概描述为“已经消耗”。实际生效及消耗由引擎结算。
- 再次拖动已准备标记可取消。出牌时提交已准备光环；无效光环按 `AuraResolver.CollectRefunded` 的结果退回。
- 防御光环须主动选择，未选择的加值不计入预算；免疫符合条件时可直接完成防御，不提交防御牌。
- 来源回手、指示物消耗或失效后同步更新图标。动画时长、坐标不在本文重复维护。

## 信息可见性

对手手牌按已知 / 未知信息显示。查看效果中的未知牌使用牌背，不通过选项、提示或日志泄露名称。
点击对手角色可显示当前局面的 AI 出牌元素预判；由 `BattleDriver.ForecastAttackElement` 提供，不承诺后续一定出该牌。

同机双人热座会随当前决策切换本机座位和手牌视角，不代表已具备网络对战或隐藏信息隔离。

## 维护

`BattleUi` 负责决策绑定，`HandView`、`HudBuffView`、`PreparedAuraView` 等负责输入与展示。新决策、重开和终局时清理旧选择、准备态与提示；节点接线同时检查场景及 Prefab。
