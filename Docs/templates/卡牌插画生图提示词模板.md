# 卡牌插画生图提示词模板

> 用途：复制本文件，替换尖括号内容后提交给 LikeAI 文生图接口。
> 这是**插画层**模板，禁止在图中生成卡名、数值、效果文字或卡框。

```text
Use case: stylized-concept
Asset type: game card illustration
Primary request: Create a completely new illustration named <中文名> (<English name>) for a magical elemental card game.
Input images: none. Use text-only generation; do not copy any existing card composition.
Scene/backdrop: <极简抽象背景；只保留支撑主体的环境层>
Subject: <一个主形体；说明元素、动作、方向、尺度、焦点和必要的冲击细节>
Style/medium: minimal abstract low-poly digital illustration; faceted polygon planes; hard-edged triangular geometry; crisp silhouettes; flat color blocks; restrained texture; magical elemental card-art feeling; not a photo; not a 3D render.
Composition/framing: vertical portrait 2:3 card artwork; <视角>; <主体占画面比例>; <动势>; readable silhouette at thumbnail size; full-bleed artwork with no border.
Lighting/mood: <光源方向>; <明暗关系>; <情绪>
Color palette: <从元素色表选择 4–6 个颜色词>; limited cohesive palette; no unrelated warm colors unless required by the element.
Materials/textures: <大几何面、边缘高光、碎片、泡沫、火星等必要细节；避免微小噪声>
Text (verbatim): none
Constraints: no text, no Chinese characters, no numbers, no symbols, no logo, no watermark, no frame, no modern objects, no extra subjects.
Avoid: smooth gradients, painterly brushwork, photorealism, soft blurry atmosphere, ornate scenery, excessive tiny details, copying an existing card's composition.
```

## 构图填写规则

- 攻击类：写清楚冲向镜头、上冲、斜切、爆裂、压迫等方向；不要只写“漂亮的元素图”。
- 防御类：写清楚包裹、阻挡、盾面、环绕和稳定的重心。
- 状态类：用一个可读的大形体表达状态，不添加人物表情或 UI 图标。
- 水 / 风 / 电等流动元素：必须指定流线、汇聚点或冲击方向，避免生成普通风景。
- 复杂主体：优先删掉背景和小物件，保证卡牌缩略图仍然只读出一个主形体。
