# M39 · 角色架构与设置卡池

> **性质**：现行 · **最后核对** 2026-09-25

## 使用入口

打开 `Assets/Scenes/SampleScene.unity` 进入 Play：

1. 顶栏齿轮打开设置，暂停对局推进，继续游戏恢复。
2. “重新开始”使用当前已保存配置重开。
3. “测试功能 · 玩家卡池”打开全卡牌滚动列表。
4. 点击卡牌或复选框切换加入/移除；全选、恢复默认只修改当前草稿。
5. 低于角色的 `minimumCardCount` 时不能保存。默认玩家最低 8 张。
6. “保存并重开”先校验并写入成功，再立即重开；返回丢弃未保存草稿。

AI 出牌、头顶展示和飞行演出保持。用户已澄清“不显示 AI 出牌”为笔误。

## 配置位置

- `Assets/Resources/Characters/DefaultPlayer.asset`
- `Assets/Resources/Characters/DefaultMonster.asset`
- `BattleCanvas` 上 `BattleDriver._participants`：角色、控制方式、队伍。
- `BattleDriver._localSeat`：本地玩家对应哪个座位。当前界面仍为两人布局。
- Project 右键 → 创建 → 魔法乱斗 → 角色配置，可以新增角色资产。

`CharacterConfig` 提供稳定角色 ID、名称、类型、初始生命、最大生命、最少卡牌数、全卡表开关、自定义卡 ID 列表和能力列表。
`useAllCards=true` 表示默认使用全卡表；关闭后使用 `cardIds`。
测试存档只覆盖本地玩家对应角色的卡池，按角色 ID 分开保存，不修改资产，也不改变怪物配置。

## 内核和扩展

- `CharacterDefinition` 是纯 C# 静态定义，复制卡池配置。
- `PlayerState` 是每局状态，包括初始生命、当前生命、冷却区和独立 `Deck`。
- `CardPool` 是可增删的卡 ID 集合；每种卡最多一张。`Deck` 是本局有限剩余牌堆。
- `IParticipantController` 是异步决策端口。人类控制器等待输入，AI 控制器适配现有 `IAgent`，同样向引擎提交 `DecisionResponse`。
- `BattleDriver.ControllerFactory` 可以替换控制器；`ModeFactory` 可以创建新的 `IBattleMode`。
- `IBattleMode` 管理人数校验、行动顺序、敌我关系、防御目标、效果范围和胜负。`BattleOutcome.WinnerSeats` 可承载多个获胜座位。
- 当前交付 `DuelMode`。四人模式只预留接口，没有交付四人布局、联网或完整的 2v2/混战规则。不能只把 Inspector 人数改成 4 就开始游戏，需要提供对应模式和界面。
- UI 本地/对手显示绑定通过 `ConfigureSeats` 注入；区域候选改为按座位建立字典。

角色能力由 `ICharacterAbilityDefinition.CreateRuntime()` 为每个座位、每局分别创建实例。已有钩子：开局、回合开始、进攻力量、防御力量、受伤前、受伤后。
配置适配器提供治疗、抽牌、力量加值、减伤四个基础算子；复杂能力通过实现接口扩展。
力量钩子为纯查询，不能在光环准备导致的重复计算中消耗能力次数或改变状态；配置中的力量能力要求 `maxUses=0`。
其他钩子可设置 `maxUses`，0 表示无限次。无能力的默认角色保持原流程。
能力抽牌受手牌/冷却/场上在用卡的合计 8 张容量约束，避免新增能力导致冷却回手超过手牌上限。

## 保存与界面资源

- 存档：`Application.persistentDataPath/test-card-pools.json`。
- JSON 版本号为 1，保存角色 ID 与卡牌定义 ID，不保存血量、手牌 UID 或剩余牌堆。
- 临时文件写入完成后替换目标文件；写入失败保留原对局并显示原因。
- 缺少存档时使用角色默认卡池；无效存档加载失败会给出警告并回退默认卡池。保存遇到损坏/不支持版本的文件会提示失败，不静默覆盖。
- 原子替换当前针对本项目 Windows 平台；其他平台发布前需验证存储实现。
- `SettingsUiBuilder` 只追加设置子树和缺少的配置引用，不重建既有战斗美术。
- M8 构建器已调用 `SettingsUiBuilder.Ensure`，确保后续重建包含新入口。
- 复用 `CardView_Hand.prefab`、`Peek_Panel.png`、`HandPick_Confirm.png` 和既有字体。
- 设置层独立排序，遮罩阻止底层点击；卡池只实例化已有条目模板。
- 设置暂停 `BattleDriver` 的推进、AI 等待和节拍，不以 `Time.timeScale` 控制；已启动的装饰动画可以完成。
