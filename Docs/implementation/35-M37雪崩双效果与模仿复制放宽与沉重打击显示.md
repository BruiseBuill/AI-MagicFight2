## 1. 需求 1：雪崩（an）从「可选的单效果」变成「强制双效果」

### 1.1 改之前是什么样

```csharp
Add(39, "an", "雪崩", 6, 3,
    A(EffectOp.SlowZoneBoth, 1, text: "可使双方冷却区中剩余冷却为 1 的法术都被减速"));
```

`SlowZoneBoth` 走的是和「区域加速 / 区域减速」同一条路（`IssueZoneValue`）——
它列出了 `[不执行] + [双方冷却区中剩余冷却 = 1 的 N 张法术全体减速]` 两项，
玩家**点进去只是为了确认**（或者放弃）。界面上就是那个「区域减速：选一个剩余冷却值」的浮层。

### 1.2 改之后

```csharp
Add(39, "an", "雪崩", 6, 3,
    A(EffectOp.SlowZoneBoth, 1, text: "使双方冷却区中剩余冷却为 1 的法术全部减速"),
    A(EffectOp.QuickRefill, text: "快速回填"));
```

三处配合：

1. **卡表**去掉「可」，并补上第二条 α（快速回填）；
2. **`EffectDef.NeedsDecision`** 把 `SlowZoneBoth` 摘出去 —— 它不再产生决策；
3. **`BattleEngine.StartStage3Decision`** 把它从 `HasteZone` / `SlowZone` 那一组里
   **单独拆出来**，走新方法 `ApplySlowZoneBoth(ef)`：逐座位各跑一遍 `CooldownOps.SlowZone`，
   然后 `FlushCooldown()`，方法返回 `false`（= 没发决策，`RunStage3` 继续跑队列里的下一条）。

> **「强制」为什么不用 `EffectDef.Mandatory`**：那个字段表达的是「这个决策不可选择不执行」，
> 而这里**根本没有决策**。给一个不发决策的效果标 `[强制]`，只是多一个不会被读的字段。

### 1.3 顺手保住的既有口径

- **「无匹配目标」仍要报**：`CooldownOps.ApplyZone` 在改动 0 张时会自己补一条
  `Card = null` 的「区域减速（无匹配目标）」记录 —— M36 加的怪物效果提示条靠它说话。
  走新方法不影响这条（用的是同一个 `SlowZone`）。
- **上限仍然有效**：减速的上限 = 该牌的基础冷却值（`CooldownOps.TrySlow`），
  已经顶到上限的牌不会被这条效果推爆。
- **界面侧不用动**：`BattleUi` 里那套「区域高亮只落 8 个槽位」的逻辑本来就写着
  「只剩 `Seat = -1` 一档时两侧都不点亮」；现在连那一拍都不会来了，那段兜底留在原处
  （区域加速 / 减速仍然在用）。

## 2. 需求 3：模仿（x）的复制条件从「= 3」放宽成「≤ 3」

一个事实的**两处表达**，必须一起改：

| 位置 | 改前 | 改后 |
|---|---|---|
| 卡面文字 `CardLibrary` | 「基础冷却**为 3** 且无光环」 | 「基础冷却 **≤ 3** 且无光环」 |
| 候选过滤 `BattleEngine.IssueCopyTarget` | `c.Def.Cooldown != ef.A` | `c.Def.Cooldown > ef.A` |

「无光环」（`c.Def.HasAura`）这一半**没动** —— 光环牌被复制会把指示物一起带过来，那是另一张卡。

⚠ 只改文字漏改过滤（或反过来）时，表现是「卡面写着能复制，界面上一个候选都没有」，
**万局统计里完全无声** —— 所以这条改动配了 `MimicScenario`（见 §4）。

## 3. 需求 2：沉重打击（h）的**显示**必须和规则一致

规则侧**本来就是对的**：`AttackContext.BonusPower` 在 `NoAtkBuff` 下恒为 0，
所以「用了进攻光环照样按不变算」一直成立。

错的是**显示**：手牌上「把已准备光环的加值画到卡面上」的那套预览
（M24 #4 / `BattleUi.ApplyHandPowerPreview`）不认这个例外 ——
玩家拖好一枚进攻力量 +2 的光环，卡面把沉重打击从 7 画成 **9**，而打出去只有 7。

修法（三处、单向数据流，表现层不认卡 ID）：

```
CardDef.ForbidsAtkBuff            // 卡表里有没有 NoAtkBuff 这条效果（规则事实的唯一来源）
   └─ CardSnapshot.NoAtkBuff      // 快照透出布尔量
        └─ BattleUi.PreviewBonusFor → if (attack && card.NoAtkBuff) return 0;
```

- **只挡进攻侧**：这条规则管的是**进攻力量**，防御加值照常预览（`rules/01-规则基线.md` §6.3）。
- `BattleEngine.CardForbidsAtkBuff` 顺带改成读 `card.Def.ForbidsAtkBuff`，
  和快照走同一个判据（原来是引擎里自己扫一遍效果表）。

## 4. 验证

### 4.1 新增两条自测场景（`Tools/RuleSelfTest/`）

两条都**不打乱发牌**，而是在「进攻方选牌那一拍」用引擎自己的入口
`CooldownOps.PutIntoCooldown` 把牌从手里按指定初始冷却送进冷却区，把局面钉死。
⚠ 新文件必须同时登记到 `RuleSelfTest.csproj`（它是 `EnableDefaultCompileItems=false`，
只编译显式列出的文件）与 `Program.cs`。

**`AvalancheScenario.cs`** —— 双方各布置「剩余 = 1」一张 + 「剩余 = 2」诱饵一张，然后强制打出雪崩：

| 断言 | 抓的缺陷 |
|---|---|
| 从防御结算到下一个决策之间**不得**出现 `ChooseZoneValue` | 强制化没落地（还会弹「选一个剩余冷却值」） |
| 双方各自的「剩余 = 1」牌都被 1→2 | 只跑了一侧 / 压根没结算 |
| 「剩余 = 2」的诱饵**不得**被区域减速 | 匹配条件写得比「= 1」宽 |
| 雪崩进冷却区时 `To = 基础冷却 − 1` | 快速回填没结算 |

**`MimicScenario.cs`** —— 四个探针，每个都保证「冷却区里除注入的那张外没有别的候选」：

| 探针 | 期望 | 抓的缺陷 |
|---|---|---|
| 基础冷却 3 且无光环 | 出现在候选里 | 旧能力退化 |
| 基础冷却 2 且无光环 | 出现在候选里 | **本次放宽没落地**（旧实现这里一定是空的） |
| 基础冷却 4 且无光环 | 不出现 | 放宽过头 |
| 基础冷却 ≤3 但有光环 | 不出现 | 「无光环」这一半被一起放宽掉 |

### 4.2 反向对照（证明断言是锋利的，不是白过）

把两处改回坏版本各跑一次，断言**精确报错**：

```
[FAIL] 雪崩打出后：… · seed 3 → 雪崩仍然弹出了「选一个剩余冷却值」的区域决策 —— 强制化没落地
[FAIL] 模仿：基础冷却 = 2 且无光环的牌也可复制（本次放宽）
```

### 4.3 回归

- `dotnet run -- 10000 20261700` → **全部通过 ✅**，0 异常 / 0 违规，最长 15 回合。
- ⚠ **别用 3000 局以上的、起点 ≤ 20261601 的区间**跑回归：种子基 20260916 的
  第 685 局（seed **20261601**）会走进那份「谁都能挡住谁」的**冷战僵局**
  （内核没有平局判定，3158 回合仍在继续，被 20000 决策护栏拦下）。
  这是 M36 就登记过的既有缺陷，**与本次改动无关**；换起点到 20261700 即可避开。
- Unity 编辑器刷新后 0 error。

## 5. 需求 4：不要回滚用户在 Unity 里手改的手牌 Prefab

用户在 `Assets/Prefabs/Ui/CardView_Hand.prefab` 里手改了四处：

| 改了什么 | 具体字段 |
|---|---|
| 名称文本 | 卡名 TMP 的 `m_text` / `m_fontColor` / `m_fontSize`（72 → 64.6） |
| 三处字体加粗 | 名称 + 力量 + 冷却三个 TMP 的 `m_fontStyle` 0 → 1（Bold） |
| 名称背景框 | `AnchoredPosition.x` 50.7 → 52.5、`SizeDelta.x` 301.2 → 356.6、`Image.m_Color.a` 0.62 → 0.76862746 |

处置：**本轮一个构建器都没跑**（M7 `UiKitBuilder.BuildCardPrefab` 会重写这个 Prefab，
`UiKitPreview` 还会把样本卡序列化进去 —— 都是这个文件的写入口）。
本轮的改动全部落在 C# 源码与文档上，不触碰任何 `Assets/Prefabs`。
改动前后对 Prefab 取 SHA-1 对账，确认未被回滚。
