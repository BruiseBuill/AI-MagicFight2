# 动画审查与统一接入

## 结论

表现层凡是会改变屏幕位置、大小、透明度或父节点的运行时操作，都应当经过动画入口；
初始化、池化回收、场景加载完成后的首次排版可以直接落位。此次统一补齐了运行时移动的主要缺口，
并用 MCP 做了 Play Mode 冒烟和实际场景截图验证。

## 分类

| 类别 | 主要位置 | 统一处理 |
|---|---|---|
| 卡牌跨区域移动 | `CardTransitView`、`CooldownView`、`BattleUi` | 手牌、头顶、冷却区之间按 UID 配对；飞行、回手、直接送冷却、永久移除、替换退回都保留同一张卡面 |
| 卡牌重排 | `HandView`、`HandPickView`、`CooldownView`、`DeckSelectView` | 位置重排使用 `UiPositionMotion`；新增卡用延迟入场，已有卡从原世界坐标滑到新槽位 |
| 光环与目标反馈 | `AuraIconView`、`HudBuffView`、`PreparedAuraView`、`CharacterView` | 换父节点保留世界坐标；回位、槽位重排、角色目标高亮使用移动 / 缩放 / 颜色补间 |
| 模态面板 | `GlobalOverlayView`、`HomeSettingsView`、`SettingsView`、`TargetPicker`、`DealView`、`CardDetailView`、`StageView` | 统一使用 `UiPanelAnimator`，淡入 / 淡出时正确处理射线，关闭完成后才失活 |
| 查看与展示 | `PeekView`、`MonsterHandView`、`PlayedCardView`、结果页 | 保留窥视翻牌和既有头顶飞行；对手手牌面板持续刷新不重播进场；结果页退场完成后才触发下一步 |
| 场景切换 | `SceneRoutes`、`SceneTransition` | 淡出、异步加载、淡入；切换期间拒绝重复导航 |
| 基础缓动与状态 | `UiTween`、`UiPositionMotion`、`UiSizeMotion`、`UiColorMotion` | 修复 `OutCubic` 退回线性的问题；补间使用 unscaled time，可暂停播放，重复目标不会重启 |

## 保持即时的操作

- 首次绑定、池化回收、重开一局时的清理。
- 编辑器构建器写入的初始布局。
- 场景加载完成后的首次布局；从上一场景过渡由 `SceneTransition` 负责。
