# 对局框架可替换 · 经典模式 · 怪物智力（2026-10-30）

> 状态：变更记录 · 本文为当时实现的快照，旧规则、卡牌及完成状态不代表当前版本。现行内容见 [当前基线](../00-当前基线.md) 与 [规则基线](../rules/01-规则基线.md)。

> 用户口径：① 角色与卡牌的框架要能换人 —— 玩家可换成 AI（两个 AI 对战），AI 也可换成玩家
> （两个玩家对战，第二名玩家将来走网络）；② 主菜单设置里加「仅用前 40 张」的经典模式；
> ③ 主菜单设置里加「怪物智力：简单 / 标准」，简单难度只会按力量从大到小出牌。

## 1. 这次改了什么（一句话）

**「谁操作哪个座位」从 Prefab 的序列化值搬到了 `GameSettings`；**
**「用哪些卡」从「卡表全量」变成了可裁剪的视图；**
**「敌人多聪明」从写死的 `HeuristicAgent` 变成了两档可选。**

引擎（`BattleEngine` / `IBattleMode` / 决策结构）**一行没改** —— 它本来就不认识「谁在按按钮」。

## 2. 原有的可替换点（这次没动，但要说清楚）

`Core/Ai/IParticipantController.cs` 早就把「异步决策端口」抽出来了：

| 实现 | 用途 |
|---|---|
| `HumanController` | 等界面回填（`UsesLocalInput = true`） |
| `AiController` | 包一个 `IAgent`，`BeginDecision` 里同步算完 |
| （未来）`NetworkController` | 反序列化远端应答，`Submit` 收包 |

`BattleDriver.CoDecision` 只问 `controller.UsesLocalInput` 决定「要不要停下来等界面」，
所以**新增一种控制器不需要碰主循环**。这次真要补的是「谁来 new 这个控制器」和
「界面认哪一边是自己」。

## 3. 座位 → 控制方式：唯一判据搬到 `GameSettings`

`GameSettings.ControlOf(seat)` 是**唯一**判据（`BattleDriver.BuildSetup` 用它填
`ParticipantSetup.Control`）：

| `MatchLineup` | 座位 0 | 座位 1 |
|---|---|---|
| `PlayerVsAi`（默认） | Human | Ai |
| `AiVsAi` | Ai | Ai |
| `PlayerVsPlayer` | Human | Human |

⚠ **它覆盖** `BattleCanvas.prefab` 上 `_participants[i].control`：名单继续表达「谁能上场 + 哪一队」，
但「这一局谁操作」是玩家在主菜单选的。默认档位与名单里原有的 0=Human / 1=Ai 完全吻合，
所以不动设置时行为与之前**逐字相同**。

⚠ `BattleEngine.Create` 判「全员 AI 就给回合上限」用的还是 `ParticipantSetup.Control` ——
所以 `AiVsAi` 会自动套上 `AiTurnLimit`，不会因为没人接而跑飞。

## 4. 本机座位（`LocalSeat`）与热座视角

- 值来自 `GameSettings.LocalSeat`，在 `BattleDriver.StartBattle` 那一刻写进
  `_activeLocalSeat`（**不写回** `[SerializeField] _localSeat`，避免 Play 模式留痕）。
- 运行时可切：`BattleDriver.SetLocalSeat(seat)`。`LocalSeat` / `OpponentSeat` 都跟着变。
- **热座**（`PlayerVsPlayer`）：`BattleUi.HandleDecision` 发现这一拍问的是另一个人时，
  先 `ClearDecision → SetLocalSeat → BindSeats → RefreshAll`，整屏（手牌 / 冷却区 /
  血条 / 光环）翻到他的座位，再照常渲染选项。
  - ⚠ 顺序不能反：不先 `ClearDecision`，上一拍的 `_pendingValid / _handPlayable` 会被
    `RefreshAll` 当成「这一拍还能点那几张」重新点亮。
  - ⚠ 角色模型（`CharacterView` 的 sprite）不跟着换 —— 它只在 `HandleStarted` 里
    `ApplyMonsterArt` 一次。热座时「你」的模型仍站在原来那一侧，只有血条与手牌翻过去。
    这是**已知限制**，不影响规则。

## 5. 经典模式：前 40 张

- 定义只有一处：`GameSettings.ClassicCardLimit = 40`，判据 `CardDef.Index < 40`
  （= 卡表顺序 = 卡面文件名 `Card_01_a_暴风雪 …` 的编号）。
- 生效点只有一处：`BattleDriver.GetCardCatalog()` —— 随机牌组、自定义牌组校验、
  卡池面板全部走它。`BattleLaunch.Validate` 与 `DeckSelectEntry` 也调同一个
  `GameSettings.Filter(...)`，所以「选不到」与「抽不到」是同一件事。
- 当前 44 张，被排除的是最后 4 张：`ao 冰霜核心` / `ap 火炬` / `aq 雷云` / `ar 地刺`。
  ⚠ `ad 吞食` 虽然也是 2026-10-29 新增的，但序号 29 在 40 之内 —— 按「前 40 张」的
  字面口径**留在经典池**。要改边界只动 `ClassicCardLimit` 一个数。
- ⚠ `ClassicCatalog.Get(id)` **转发给内层**，不在裁剪后的表里查：怪物卡池资产
  （`Resources/Pools/MonsterPool_*.asset`）里手写着 `ao` / `aq`，若这里判「不存在」，
  `CardPool` 构造会当场抛 `Unknown card ID`（症状：一开经典模式进战斗就崩）。
  让它在 `Resolve()`（遍历 `All`）时自然消失，才是想要的降级。

## 6. 怪物智力：两档

`BattleDriver.CreateAiController` 是唯一分岔点：

| 档位 | 实现 | 行为 |
|---|---|---|
| 简单 | `SimpleAiAgent`（`UseAuras = false`、`ReplaceWeakCards = false`） | 进攻只挑**当前力量最大**的一张 —— 正是用户要的「按力量从大到小打牌」；不用光环、不换开局手牌 |
| 标准 | `MonsterAgentFactory.Create(...)` | 四流派启发式 + 怪物档案 + 手写优先级，与之前逐字相同 |

⚠ 简单档不走 `aiProfile`：那是「这只怪的打法」，而简单档的定义就是「没有打法，只按力量」。
`_aiUseAuras` 也只喂标准档。

## 7. 主菜单设置面板（M50）

- 构建器：`魔法乱斗/M50 · Home 设置（经典模式 / 怪物智力 / 对局双方）`。
- 落点**两处**：`Assets/Scenes/Home.unity` 里内联的 `HomeCanvas` + `Assets/Prefabs/Ui/HomeCanvas.prefab`
  （场景里那份不是 PrefabInstance，改 Prefab 不会同步 —— 铁律 11）。
- 结构：`HomeSettingsLayer / SettingsButton（右上齿轮） + PanelLayer（默认失活）`，
  面板三行：对局双方 / 经典模式 / 怪物智力 + 返回。
- 每行是「点一下换下一档」的按钮，不是 Toggle：本工程没有 Dropdown 的既有样式，
  而 Toggle 的勾选标记必须保持 active 才亮（M43 踩过）。
- 视图只做「读 → 显示 → 切档」，值全在 `GameSettings`（PlayerPrefs 落盘，键前缀
  `MagicBrawl.Settings.*`）。

## 8. 已知限制 / 下一步

1. **网络对战未接**：`PlayerVsPlayer` 目前只在单机上跑热座。真正的双机需要新增
   `NetworkController : IParticipantController`（`Submit` 收远端应答、`BeginDecision` 发包），
   以及一个「每个客户端 LocalSeat 各设各的」的启动参数 —— 框架形状已经就位（见 §3/§4）。
2. **热座的角色模型不换边**（见 §4）。
3. **结算文案**仍是「你 / AI」二元：`AiVsAi` 观战时也会说「你赢了」。
4. 设置只在**下一局**生效（战斗里没有这两个入口）。
