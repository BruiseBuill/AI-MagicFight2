# 2026-09-30 · 卡面统一到「只有插画」：删除成品整图一族

> 用户口径：**任何地方都不要采用 `Assets/Art/Cards/` 的成品整图，把这一族图彻底删掉。**
> 本文记改动面、理由与代价。

---

## 1. 删了什么

`Assets/Art/Cards/` —— 40 张 760×1056 的**成品整图**
（卡框 + 插画 + 卡名 + 力量 / 冷却 / 效果文字，全部烘焙在 PNG 里），连同 `.meta` 一起删除。

- 备份：`Artifacts/backups/2026-09-30-artcards-removed/`（40 张原图）。
- git 里也还有历史版本（这一族此前是 tracked 的）。

---

## 2. 为什么要删

不是审美问题，是**同一个事实有两个来源**：

- 成品整图把「卡名 / 力量 / 冷却 / 效果文字」烘死在图里，而 `CardLibrary.cs` 是这些事实的**另一个来源**；
- 两者一旦不同步，同一张牌在不同界面会显示两个数 —— 2026-09-28 磁暴 / 引雷互换力量时，
  就必须回头去改 `Card_12_l_磁暴.png` 里烘焙的数字，否则「手牌（组成式卡面）写 2、
  长按详情（成品整图）写 3」；
- 而 2026-09-29 新增的毒刺（`ao`）/ 击穿（`ap`）**根本没有整图**，于是头顶出牌展示
  直接退化成一块纯色 —— 用户 2026-09-30 报的「敌人头顶的卡牌显示异常（一块黑）」就是它。

删掉之后，**卡面的一切文字与数值只有「TMP 现场渲染」这一条来源**，图片只负责插画。

---

## 3. 改了什么

| 位置 | 改动 |
|---|---|
| `CardArtLibrary` | 删 `Entry.Art`、`GetArt()`、`EnsureMap()`（以及临时的 `GetFace()`）；`Illustration` 成为唯一一份图 |
| `UiKitBuilder` | 删 `ArtDir` 常量；映射表只扫 `Assets/Art/CardArt/`；不再输出「卡面缺失」告警 |
| `PlayedCardView` | 头顶出牌展示改用 `GetIllustration` —— **本次黑块的直接原因** |
| `CardTransitView` | 飞行卡（头顶 → 冷却槽）同上 |
| `CardView` | 插画槽的退化链从「插画 → 整图 → 纯色」收成「插画 → 纯色」 |
| `HandPickView` / `MonsterHandView` / `PeekView` | 去掉「整图优先」那一步，直接取插画 |
| `UiLayout` / `BattleUiBuilder` / `CardArtLibrary` | 过时注释改成现行口径 |

⚠ 全工程再搜 `GetArt` / `Entry.Art` 已无引用；剩下的 `TryGetFaceRect` 是「取卡位矩形」的方法名，与整图无关。

---

## 4. 代价（要留意的）

**头顶出牌展示、长按放大、飞行卡现在是一张「无框无字」的插画** —— 卡名与数值都不在图上了。

- 手牌 / 冷却迷你卡 / 选牌弹窗 / 看对方手牌**不受影响**：它们本来就是组成式卡面或吃插画；
- 头顶展示与长按放大若要「带卡框、带数字」，得把那两处也换成**组成式卡面**
  （即 [M38](36-M38卡面统一到单一Prefab.md) 里记的那一族「还没统一」的显示位）——
  **本次没做，等用户确认**。

## 6. 复现命令

删图必须在 Unity 里走 `AssetDatabase.DeleteAsset`（直接删文件夹会留下 `.meta` 与悬空引用）：

```
AssetDatabase.DeleteAsset("Assets/Art/Cards");
AssetDatabase.Refresh();
```

⚠ MCP 的 `execute_code` 对删除类 API 有**默认拦截**，显式意图要带 `safety_checks: false`。
