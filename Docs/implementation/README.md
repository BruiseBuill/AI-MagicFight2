## 3. 编号约定（免得下次又猜）

- **文件名前缀 `08-`…`34-` 是「实现记录的序号」**，不是模块号，也不与 `01–07` 连着排
  （`01–07` 那批是最早的规则 / 工程 / 验证文档，现在分别在 `../rules/`、`../engineering/`、
  `../validation/` 里）。
- **模块号是 `M<数字>`**（M7…M38），只出现在标题与正文里；两者**不同步**，取号前先 `ls`
  本目录看最大编号。下一次新文从 **`37-`** 起。
- ⚠ 历史上的坑：`M23` 那批（美术三件套）只记在 `.workbuddy/memory` 里、**没有实现文档**，
  所以编号 `22-` 直接跳到 `23-`；代码注释里还出现过与工程规划不一致的 M12/M13（见
  [12 号文档](12-手牌交互实现说明.md) 开头的说明）。
