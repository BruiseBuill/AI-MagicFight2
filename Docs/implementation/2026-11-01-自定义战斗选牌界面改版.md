## 新增的三处可见性

1. **占用态**：被另一方选走的牌压暗（`CardView.SetDimmed`）+ 底部挂「对手已选」标签
   （`TakenTag` 建在卡表模板上，克隆自带；`raycastTarget = false`，点击仍穿到卡面）。
   旧版没有任何标记，点了只弹一句提示 —— 玩家看到的就是「点了没反应」。
2. **8 格补全**：空位有虚线框（`HandPick_SlotDash.png`）与编号 1–8；有卡时右上角出现 × 移除键
   （30 × 30，锚点格角，`SetAsLastSibling` 保证压在卡面上）。
3. **底部提示**实时给出「还差 N 张（你）+ M 张（对手）」。

`DeckSelectView` 新增事件：`SlotRemoveClicked(int)`、`ClearClicked`；
`ShowCatalog` 多收一个 `takenIds`。8 格与「× 删哪一张」共用 `DeckSelectEntry.ResolveIds`（卡表顺序），
否则格子下标和列表下标对不上。

## 踩到的四个坑

1. **视口上沿被面板头盖住**：`Viewport` 的 `offsetMax.y` 一开始给的是 `-18`，
   而头部占 16…50 —— 第一行卡的上半截被压在头下面，看着像「卡表一进来就滚到中间」。
   改成 `-58`。
2. **cell 不能比卡面大**：`CardView` 的 RectTransform 是**布局占位**，卡面是内部 `FaceRoot` 缩放
   （`SetFaceWidth`）。cell 给 184 塞 168 的卡，行距凭空多出 23 px，看着像卡片被压扁在一堆空白里。
   cell 必须等于卡面尺寸。
3. **空位只隐藏不 `Clear`**：`CardView.HasCard` 会一直是 true，切页签后 8 格继续报「填满」
   （探针 `FilledSlotCount` 从 3 变 0 的验证里抓到）。空位必须先 `Clear()` 再 `SetVisible(false)`。
4. **`List<T>` 索引器不能 `ref`**：`UnhookButton(_slotRemoves[i], ref _removeHandlers[i])`
   编译报 CS0206，得取出来、解绑、再写回。
