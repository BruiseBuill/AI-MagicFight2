# AI 光环使用方案 v2（2026-11-01 · B1–B3 已实施）

> 状态：`Core` 已改、独立编译 0 警告 0 错误；300 局同种子对照见 §8。
> v1 的三条待确认已由用户定稿：**免疫能用就用（含连击流派）**、**进攻力量以 9 为上限**、**不做反免疫避让**。
> 未改引擎 / UI / 资产；`SimpleAiAgent` 基线保持原样。

---

## 0. 一句话

**免疫光环只要这一拍能用就花掉**（不交牌、来源牌回手即作废，连击流派同样适用）；
**进攻力量光环只在「当前牌的力量 + 这枚加值 ≤ 9」时使用**（9 = 全卡表最高防御力量，再加不会让更多牌挡不住）；
不做反免疫避让。

300 局实测：进攻光环使用率 **0% → 64.2%**，每局作废光环 **4.76 → 1.26 张**，免疫使用率 **26.7% → 100%**，
平均回合 **11.3 → 9.5（−16%）** —— 最后这条是这次改动的副作用，见 §8。

---

## 1. 改了什么（旧 → 新）

| 场景 | 旧口径 | 新口径 |
|---|---|---|
| 进攻光环 | `AurasForAttack` 恒 null，一枚都不烧 | 力量加值按「≤9」逐枚烧；连击 / 快速回填能用就用 |
| 防御·免疫 | 排在零补值挡牌之后；连击流派直接跳过 | **提到最前，能用就用**；连击流派照用 |
| 防御·连击流派 | 完全不动用任何光环 | 免疫照用；**力量光环**仍不用（手牌留给连击） |
| 反免疫避让 | 设计稿里有（未实施） | **取消**，不为了绕开免疫区间调力量 |

旧口径的实测问题（10-31 审计）：2 588 次进攻光环机会 **0 次使用**、1 428 张光环作废；
免疫 165 次可选只用 44 次，71.5% 改成交牌。

## 2. 三条原则

1. **光环是会过期的一次性资源。** 来源牌回手时未使用的指示物失效 —— 所以「能不能用」比「值不值得留」更重要；留着不用，价值就是 0。
2. **伤害恒为 1 点，力量只决定「挡不挡得住」。** 9 是卡表最高防御力量（地刺 / 陨石 / 滚石 / 冰封铠甲 / 冷冻核心），推到 10 以上不会让更多牌挡不住。
3. **只用公开信息。** 可读对方 HP、手牌**数量**、冷却区（含已激活光环）；不读对方手牌内容。

## 3. 光环的经济学（为什么免疫优先）

| 资源 | 分值 | 说明 |
|---|---|---|
| 1 点 HP | 100 | 4 HP = 一条命；HP=1 时按 1000 算 |
| 一张普通手牌 | 20 | 进冷却、之后回手 |
| 一张流派核心牌 | 35 | 连击 / 区域 / 双发 / 回血 |
| 一枚光环（保留价值） | 30 × 期限系数 | 期限系数：r≥3 → 1.0、r=2 → 0.6、r=1 → 0.3 |

免疫不交牌（只花 1 枚光环），而交牌至少要付 20 分；光环本身还会过期。
所以「免疫优先」在这张表上是**严格更便宜**的一条路，不需要再按剩余冷却分档。

> 术语：**零补值挡牌** = `Option.Value == 0`，即这张牌靠自身防御力量就够挡、不需要光环补值。
> **它仍然要交出去**（双发交两张、进冷却），不是「免费」。

## 4. 进攻侧

### 4.1 力量加值：以 9 为上限

```
p = card.EffectivePower                       // 当前进攻要打出的牌的力量
对每一枚可用的力量光环（AtkPower / AtkOrDefPower），按加值从大到小：
    if (p + 光环值 > 9)  → 跳过这一枚，不用
    else                 → 用掉，p += 光环值
```

- **降序遍历**：牌面 8 时 +4 / +3 / +2 都塞不下，最后 +1 刚好到 9 —— 不会因为最大那枚塞不下就整批不用。
- **同加值**：`AtkPower` 先于 `AtkOrDefPower`（后者还能在防御侧补值，进攻侧先用专用的）。
- **不刻意压低或抬高力量**：取消「反免疫避让」，不为了绕开对方免疫区间做额外判断。
- **沉重打击**（`ForbidsAtkBuff`）：一枚都不烧（引擎本来也会整批退回）。

### 4.2 连击 / 快速回填

| 光环 | 条件 | 处理 |
|---|---|---|
| 连击（引雷，基础力量 ≤6） | 卡面不自带连击、手牌 ≥2（打完还剩一张能接） | 用 |
| 快速回填 | 卡牌基础冷却 ≥2 | 用 |
| 连击 | 手牌只剩这一张 / 基础力量 >6 / 卡面自带连击 | 不用 |

两者都只有进攻场合可用、且来源牌会过期，所以不参与 9 这条线的比较。

### 4.3 伪代码

```csharp
// AuraPolicy.PickAttackAuras
int[] PickAttackAuras(req, card, state)
{
    if (card == null || card.Def.ForbidsAtkBuff) return null;

    var picked = new List<Option>();

    Option combo = PickCombo(req, card, state);      // §4.2
    if (combo != null) picked.Add(combo);

    PickPowerAuras(req, card, picked);               // §4.1：降序、>9 跳过
    PickQuickRefill(req, card, picked);              // 冷却 ≥2

    return picked.Count == 0 ? null : Indices(picked);
}
```

> ⚠ 9 的判据用的是**决策时**的 `EffectivePower`。磁暴烧牌 +3、灼烧按掉血 +N 这类
> 「结算第 ① 步才加进去」的增量不在其中，最终力量仍可能超过 9（实测只有 2.2% 的攻击带增量）。

## 5. 防御侧

### 5.1 顺序（新）

| 层 | 条件 | 动作 |
|---|---|---|
| **L0** | 双发「行动修正」：手里有可用免疫 | **不掷骰，恒防**（免疫能免掉整次攻击） |
| **L1** | 有可用免疫光环 | **用免疫**（不交牌；连击流派同样适用） |
| **L2** | 有零补值挡牌 | 交防御力量最小的那张（连击流派只挑非连击 / 非区域加速的牌） |
| **L3** | 连击流派，且没有 L1 / L2 | 放弃防御（手牌留给连击） |
| **L4** | 其余 | 报备防御力量光环补值 → 交牌；补不出就掉血 |

> L1 之所以无条件优先：免疫是**唯一不交牌**的手段，而且来源牌回手就作废。
> 旧口径把它排在零补值挡牌之后，导致 71.5% 的免疫机会被「交一张牌」替代，最后随来源牌作废。

### 5.2 力量光环补值（只在 L4）

- **只补到够**：`need = 进攻力量 − 该牌防御力量`，贪心取加值最大的组合（沿用现有 `PickDefenseAuras`）。
- 双发时 `need` 是两张牌的补值之和，引擎按新预算重发本拍，第二次才真正交牌。
- 补不出来就掉血：`1 HP = 100`，但如果需要 3 枚以上光环才能挡，仍然比掉血便宜（3 × 30 = 90 < 100）。

### 5.3 石盾 `al`（免疫 ≤3）

实测双发 1 349 次里 **79.4% 的最终力量 ≤3**，所以它是**反双发专用免疫**，不是废牌。
新顺序下它从「用 22 次」变成「用 70 次」（作废率 50% → 16%），印证了这一点。

## 7. 验收与实测（300 局 / 种子 8100–8399）

| 指标 | 旧口径 | 新口径 |
|---|---|---|
| 进攻光环使用 | 0 / 2 588（0%） | **941 / 1 466（64.2%）** |
| 免疫「可选 → 使用」 | 44 / 165（26.7%） | **90 / 90（100%）** |
| 免疫作废率（石化 ak / 石盾 al） | 33% / 50% | **26% / 16%** |
| 每局作废光环牌 | 4.76 | **1.26** |
| 防御力量光环使用 | — | 536 / 1 402（38.2%） |
| 平均回合 | 11.3 | **9.5（−16%）** |
| `Rejected` / `Stall` | 0 / 0 | **0 / 0** |

**定向探针**（同一份手牌）：
- 无牌可挡 + 免疫可用 → 用免疫 ✓
- **有零补值牌可挡 + 免疫可用 → 仍用免疫**（旧口径是出牌）✓
- **强制连击流派 + 免疫可用 → 用免疫**（旧口径是放弃）✓
- 石盾在力量 2 时给出并消耗；力量 4 / 6 / 8 时引擎按区间滤掉 ✓

**为什么进攻使用率不是 100%**：分母是「至少有一枚可用光环」的进攻拍；
牌面已经是 9、或加值最小的那枚也会超过 9 时，按规则就是不用 —— 这正是 9 这条线的预期行为。

## 8. 风险与待观察

| 风险 | 数据 / 说明 | 处理 |
|---|---|---|
| **对局明显变短** | 平均回合 11.3 → 9.5（−16%），超出「±10%」的验收线 | 先观察玩家体感；若太快，优先调「9」这条线或给光环加值设递减，而不是回退免疫 |
| AI 变强 | 进攻穿透率上升，玩家更容易掉血 | 正式版可按怪物分档（原 AuraStyle）单独做，不混进本次规则 |
| 免疫被烧在很小的攻击上 | 用户明确口径：不用会过期，所以能用就用 | 接受；这是设计选择，不是 bug |
| 9 的判据不含结算期增量 | 磁暴 / 灼烧可能把最终力量推到 9 以上 | 只有 2.2% 的攻击有增量；若体感「莫名其妙巨大」，再补一步「结算前预估」 |

## 9. 附录 · 进攻力量实测（决定「9」这个数）

工具：`_audit/power-probe`（300 局 / 7 029 次攻击）。

**卡表基础力量 1–9**：1:4、2:4、3:6、4:6、5:6、6:6、7:5、8:4、9:3。

**实战最终力量**：1–11，中位 **5**、平均 5.33、p25–p90 = 4–8；≥6 占 43.7%、≥8 占 18.8%、≥10 仅 0.4%。

**各力量的实际挡率**：

| 进攻力量 | 4 | 5 | 6 | 7 | 8 | 9 | 10 |
|---|---|---|---|---|---|---|---|
| 挡住 | 90.5% | 75.7% | 81.2% | 70.7% | 64.4% | **49.8%** | 15.0% |

> 9 是分水岭（约一半能挡），10 才接近必穿；但 10 需要额外的加值，而 9 已经是卡表最高防御力量。
> 用户口径取 9 作为上限，意味着「最多推到刚好压过所有非守护牌」。

**双发子集**（1 349 次）：2 = 49.7%、3 = 29.4%、5 = 20.4% → 石盾 `al` 覆盖 79.4% 的双发。

## 附：与现有规则的边界

- 光环仍然「来源牌作为进攻牌进冷却区后获得」；本方案只决定**何时消费**。
- 免疫仍然「按最终进攻力量判定、覆盖整次攻击（含双发）、空手可用」。
- 连击光环仍然「基础力量 ≤A、不可叠加」；硬过滤与引擎 `CollectRefunded` 同源。
- 「未实际生效的已准备光环不消耗」不变。
