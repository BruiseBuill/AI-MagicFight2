# 游戏开始场景（P0 · Home）

> 状态：已实现并端到端验过 · 日期：2026-10-05 · 范围：新增 `Home` 场景 + 它把「选存档」接进了主链路

## 1. 用户口径

- 「做一个极简的游戏开始场景，这个开始场景当中可以选择当前的所有存档，选择存档之后可以进入游戏。」
- 「当玩家在战斗当中失败，点击退出时，也是返回该界面。」
- 另：进 Play 时 Console 刷字体相关的 `MissingReferenceException` → 见
  [编辑器内置字体图集索引失效排查（2026-09-30 · 复发补记）](../validation/2026-09-30-编辑器内置字体图集索引失效排查.md)。

## 2. 界面长什么样

整屏纯色底（`UiTheme.Backdrop`）+ 居中一列，从上到下：

| 元素 | 内容 | 版式常量 |
|---|---|---|
| 大标题 | 「魔法乱斗」 | `UiLayout.HomeTitleY` / `FontSizeHomeTitle` |
| 副标题 | 「选择存档 · 进入冒险」 | `HomeSubtitleY` |
| 存档行 ×2 | 左：档名（`SaveSlots.DisplayName`）· 右：状态 | `HomeRowWidth` / `HomeRowHeight` / `HomeRowY(i)` |
| 「进入游戏」 | 按钮 | `HomeEnterWidth/Height/Y` |
| 提示行 | 「已选中 主存档（存档 2） · 10 张牌」 | `HomeHintY` |

- **状态文案**：没有存档文件 → `新档 · 还没有卡池`（测试档是 `空 · 用角色自带卡池`）；
  有 → `N 张牌`；读不出来 → `读不出来`。
- **选中态用描边不用换色**：每行底板上挂一枚 `Outline`（金色），默认 `enabled = false`，
  选中时打开。铁律 3（颜色只写 prefab `Image.color`，运行时只切 active / enabled）——
  改底色的话那个颜色进不了 Prefab，构建器重跑一次就丢。

## 3. 落地在哪

| 文件 | 作用 |
|---|---|
| `Assets/Scripts/Unity/Configuration/GameSession.cs` | **本次游戏选中的档位**（静态）。`Choose(slot)` / `Forget()` / `HasChosen` |
| `Assets/Scripts/Unity/Ui/HomeView.cs` | 视图：摆 + 报（`SlotClicked` / `EnterClicked`），不认规则 |
| `Assets/Scripts/Unity/Ui/HomeSceneEntry.cs` | 入口：读存档状态、铺界面、点了「进入游戏」就切 `Map` |
| `Assets/Scripts/Unity/Editor/HomeUiBuilder.cs` | 构建器：菜单 **`魔法乱斗/P0 · 构建 Home 场景`**（幂等、无弹窗） |
| `Assets/Scenes/Home.unity` + `Assets/Prefabs/Ui/HomeCanvas.prefab` | 生成的场景与界面 Prefab |

改动：

- `MapRoutes`：新增 `HomeScene = "Home"`；`BuildOrder` 里 **Home 提到第一位**
  （= 正式构建的启动场景从「地图」变成「开始界面」）。
- `BattleDriver`：`ActiveSaveSlot` 改为
  **`GameSession.HasChosen ? GameSession.Slot : _saveSlot`**，并且**内部的读 / 写也改走这个属性**
  （原来读档 / 存档两处直接用 `_saveSlot`）。没选过档时仍听 Inspector 的值
  —— 单场景调试不被主菜单影响。
- `BattleUi.HandleQuitBattle`：**失败界面的「退出」一律切 `Home`**（原来分「冒险里回地图判失败 /
  单场景停战」两条路），并在切之前 `MapRun.Clear()`。

## 4. 完整链路

```
Home ──选档 + 「进入游戏」──▶ Map（MapRun.Clear() → 地图自己开一趟新的）
  ▲                             │
  │                             ├─ 事件节点 → Shop / WitchWorkshop / Upgrade → 「离开」→ Map
  │                             └─ 战斗节点 → SampleScene → 赢：ResultWinRoot「继续」→ Map
  │                                                        └ 输/平：ResultLoseRoot
  │                                                             ├「重试」= StartBattle(LastSeed) 原地重打
  └────────────「退出」= MapRun.Clear() + LoadScene("Home") ◀────┘
```

## 5. 两条要记住的判据

1. **进游戏时 `MapRun.Clear()` 不是可选的**：`MapRun` 是静态的、换场景不重置。
   不清的话玩家从主菜单点「进入游戏」会直接掉进上一趟已经打输（或走到一半）的地图里
   —— 而地图那边会规规矩矩地铺出「旅程结束」。
2. **`HomeSceneEntry` 读存档状态必须先用 `SaveStore.Exists`**：
   `TryLoadPlayer(SaveSlot.Main)` 在文件不存在时会**当场随机开一个新档并落盘**
   —— 只想看一眼「有没有存档」，就会凭空写出一份 8 张牌的新档。

## 6. 踩坑

- ⚠ **`HomeView` 的按钮监听器首轮没生效**（点「进入游戏」毫无反应、零报错）。
  现象：存档行的按钮点得动，唯独「进入游戏」那枚不响。
  处置：把注册从「只在 `Awake` 里 `AddListener`」改成 **`Awake` + `OnEnable` 都调用一个
  可重入的 `Hook()`**（`Hook` 内部先 `RemoveListener` 再 `AddListener`，
  委托存在字段里所以摘得掉）。改完实测一击即中。
  ⚠ 顺带把 `OnDestroy` 里的 `RemoveAllListeners()` 换成了配对的 `Unhook()`
  —— `RemoveAllListeners` 会把按钮上**别人的**监听器也一起清掉。
- ⚠ **`Application.CanStreamedLevelBeLoaded(MapRoutes.HomeScene)` 是退出键的兜底**：
  `Home` 没构建 / 没登记进 Build Settings 时 `LoadScene` 会当场抛错、把玩家卡在失败界面。
  判一下就不在能加载时退回旧行为并打警告。
- ⚠ 构建器存 Prefab 后**场景里那份不是 Prefab 实例**（与其它场景同一条）——
  以后给 Home 加节点，Prefab 与场景两处都要补。

## 7. 验证记录（2026-10-05）

- `HomeUiBuilder.RunAll()`：新建 `Home.unity`、存出 `HomeCanvas.prefab`、
  Build Settings **6 个场景（新登记 Home，启动场景 = Home）**。
- 进 Play（Home）：Console **0 error / 0 warning**（字体那条已不再刷）；
  界面上两行存档读到 `主存档（存档 2）· 10 张牌` / `战斗测试档（存档 1）· 空 · 用角色自带卡池`。
- 点存档行：提示行与金色描边按预期切换（`edge0=True edge1=False`）。
- 点「进入游戏」：`GameSession.HasChosen=True`、场景切到 `Map`、`MapCanvas` 铺开、
  `MapRun.Graph` 21 个节点。
- 失败退出：在 `SampleScene` 里调 `ShowResultLose` 铺出失败界面 → 点 `QuitButton`
  → 场景切回 **`Home`**、`HomeCanvas` 在、`MapRun.Graph == null`。

## 8. 已知遗留

- 存档行**只列 `SaveSlot` 现有两个档位**（`HomeSceneEntry.SlotOrder`）。
  要加存档位得同时想清楚「新档位的初始卡池从哪来」（`SaveSlot` 的类注释里写着这条）。
- 「金币」「这一趟冒险走到哪」**都不在存档里**（金币只活在 `MapRun`）——
  所以从 Home 重新进游戏 = 金币回到 50、地图重生成。这是当前口径，不是 bug。
- 开始界面**没有任何过场 / 音效**（用户要的就是「极简」）。
