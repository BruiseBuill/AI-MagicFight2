# 工程规划

> 状态：现行 · 更新日期：2026-10-30 · 范围：开发范围与后续工作；不作为验收报告。

## 当前范围

- 独立卡牌对战：标准随机牌组、自定义牌组。
- 玩家对 AI、AI 对 AI、同机双人热座；网络对战尚未实现。
- 当前卡表 44 张，经典模式启用前 40 张。
- 纯 C# 规则内核与 Unity 表现分离；模块入口见 [架构与接口](04-架构与接口.md)。

当前功能与验证边界统一维护在 [当前基线](../00-当前基线.md)。已删除的冒险及其存档、商店、强化不属于当前开发范围。

## 后续顺序

1. 按 [规则与实现差异](../rules/03-规则与实现差异.md) 修正规则实现，并补充对应场景验证。
2. 使用 Unity 实际启动配置验证发牌、替换、连击、光环和三种控制方式。
3. 验证完整流程：Home、选牌、战斗、结算、重试与退出。
4. 检查热座的角色显示、信息可见性和结算称谓。
5. 规则与交互稳定后再推进网络控制器或其他玩法。

## 验收要求

默认采用 [轻量检查原则](文档规范.md)：一次编译及少量相关场景即可，界面只快速检查改动处。上述后续事项是开发方向，不是每次修改都要执行的验收清单。不要求随机对局、全量测试、全流程或单独验证报告；存在具体问题时再有针对性地补查。

初版模块编号、完成勾选和旧统计见 [整理前快照](../archive/20261030-文档整理/03-工程规划.md)。
