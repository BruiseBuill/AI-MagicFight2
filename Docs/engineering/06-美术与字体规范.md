# 美术与字体规范

> 状态：现行 · 更新日期：2026-10-30 · 范围：资源与文字规范；本次未重新验收视觉效果或字体覆盖率。

## 卡面与插画

所有卡面使用组成式组件：插画、卡框、图标和 TMP 文本。卡名、力量、冷却和效果文字不烘焙进图片，不再使用已删除的 `Assets/Art/Cards/` 完整卡面。

| 资源 | 位置与约定 |
|---|---|
| 正式插画 | `Assets/Art/CardArt/Card_<两位序号>_<卡ID>_<卡名>.<ext>`；序号按当前卡表顺序 |
| 候选图 | `Assets/Art/CardArt/_Draft/`；尚未接入卡表的图不进入运行时映射 |
| UI、图标、角色 | 分别位于 `Assets/Art/Ui/`、`Icons/`、`Chars/` |
| 第三方素材 | `Assets/ThirdParty/`，遵循各素材包目录与许可 |
| 过程与验收图 | `Artifacts/` 或 `Captures/`，不混入正式插画 |

当前卡牌 ID 为 a–ar，共 44 张；完整卡表只在 [卡牌图鉴](../rules/02-卡牌图鉴.md)维护。原图、导入资源与运行时映射是否齐全需分别检查，不能用卡牌数量代替资产验收。

插画默认使用 Sprite、Single、PPU 100、最大纹理尺寸 2048；特殊资源按消费者需要设置。可拉伸 UI 使用九宫格，边距由切图确定；不得以统一边距裁掉图案。

## 字体

| 用途 | 字体 |
|---|---|
| 正文、数值 | Noto Sans SC，`Assets/Art/Fonts/Black/Google-Regular.ttf` |
| 标题、卡名 | 站酷仓耳渔阳体 W03，位于 `Assets/Art/Fonts/BlackLike/` |
| 纯英文点缀 | ZCOOL Addict Italic 02，位于 `English-Handwriting-Italy/` |
| 可选大字点缀 | 站酷快乐体，位于 `HandWriting/` |

- TMP 资产使用明确的 fallback，新增字体须检查中文、数字、括号及比较符号。
- Dynamic SDF 运行时补字依赖源字体，保留相应 TTF / OTF。
- 伪粗体依赖 SDF 材质支持，不能假定字体自带粗体字重。
- 触发符号由图标库提供；语义为剑、盾、特殊效果符号。当前部分素材将特殊效果画作感叹号，原版说明为圆圈，两者都对应 γ，不表示另一种效果。
- 小卡面长文通过详情面板阅读；在实际显示尺寸检查截断、缺字、对比度及点击遮挡。

## 接入与检查

变更美术后更新对应资源映射，并检查手牌、出牌、详情和冷却区使用同一份卡面数据。保留已有 `.meta` 和 GUID；资源移动遵循 [目录规范](项目目录规范.md)。

卡牌风格、提示词和生图流程见 [插画工作流](07-卡牌插画美术与AI生图工作流.md)。旧版整图映射、字体数量与覆盖统计见 [历史快照](../archive/20261030-文档整理/06-美术与字体规范.md)，不得作为当前验证结果。
