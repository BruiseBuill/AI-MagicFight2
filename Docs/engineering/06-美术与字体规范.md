### 2.2 命名规范

```
Card_<两位序号>_<卡ID>_<卡名>.png
     │         │       └── 中文卡名，与 02-卡牌图鉴.md 一致
     │         └── 文档中的卡 ID（a–an），CardLibrary 的录入依据
     └── 01–40，等于卡表行序
```

- **带序号**是为了让工程窗口按卡表顺序排列。只用 `Card_a_…` 会排成 `a → aa → ab … → an → b`，与文档顺序不符。
- **保留卡 ID** 是为了代码侧直接对应 `CardDef.Id`，不必再做一次映射。
- `.png.meta` 与 `.png` 同步改名、**内容原样保留**，因此 GUID 不变，已有/将来的引用不会断。

### 2.5 ⚠ 对表现层的设计影响（重要）

卡面文字**已烘焙**，这带来两条约束：

1. **手牌区可以直接用整图**——不需要再叠 TMP 文本，`Docs/engineering/03-工程规划.md` §7 里"色块底 + TMP 文本"的占位方案**已被真实卡面取代**。
2. **冷却区的迷你卡不能复用整图**——迷你卡要显示**动态的剩余冷却**（会随加速/减速变化），而整图上的数字是固定的基础冷却值。
   → 迷你卡仍需"卡框 + TMP 文本（卡名 / 力量 / 剩余冷却）"的合成方案（见 `Docs/rules/05-决策记录.md` D4）。
   → 若希望迷你卡也有插画，需要把 40 张图**拆成"插画区"与"卡框区"两层**，这是一项额外工作，本期建议先不做。

另外：光环指示物（未使用亮 / 已使用灰）也必须在运行时叠加，不能靠卡面表达。

**⚠ 两点设计上的注意**

1. **原图比例 ≠ 卡面比例**：原图 `784×1168`（0.671），卡面 `760×1056`（0.720）。
   卡面不是原图的等比缩放，而是**重新排版**（裁切 + 加卡框 + 烘焙文字）。
   因此**不能把原图当卡面直接塞进 `Image`**，否则构图会被拉伸。
2. **`.jpg` 无 Alpha 通道**：26 张 jpg 是不透明的满幅插画，做成圆角卡片时需要遮罩
   （`MagicCardKit/Materials/CardMask.mat` 正是干这个的）。
   `.png` 的 14 张多数也没有 Alpha（`RGBA` 只出现在 `引雷`、`狂躁蘑菇` 等少数几张）。

### 2.8 触发图标与特效

卡面上的 α / β / γ 符号说明「这条效果什么时候结算」（见 `Docs/rules/01-规则基线.md` §通用原则）。
卡面文字是烘焙死的，但**迷你卡、详情浮层、提示条的文字要由 TMP 现场渲染**，符号必须由 Sprite 提供。

| 文件 | 符号 | 含义 | 代码对应 |
|---|---|---|---|
| `Art/Icons/Icon_01_attack_剑.png` | α | 剑 = **进攻时**结算 | `EffectTrigger.Attack` |
| `Art/Icons/Icon_02_defend_盾.png` | β | 盾 = **防御时**结算 | `EffectTrigger.Defend` |
| `Art/Icons/Icon_03_special_感叹号.png` | γ | 感叹号 = **特殊时机** | `EffectTrigger.Special` |
| `Art/Icons/_Source/IconSheet_盾剑特殊_三合一.png` | — | 切分前的三合一拼图 | 留档，**不当成品用** |
| `Art/Fx/Fx_Explosion_Light.png` | — | 橙色星爆光效 `1135×1079`，透明底 | 被 `BigMagicCard.prefab` 引用 |

**切分口径**（脚本 `Tools/art-audit/slice_icons.py`）

- 按 **alpha 列分布自动找分界**，不硬编码坐标 —— 同类拼图换个数量也能用。
- ⚠ **源图从左到右是「盾 / 剑 / 感叹号」**，但文件序号按 `EffectTrigger` 枚举序排
  （`Attack=0 → 01` 剑、`Defend=1 → 02` 盾、`Special=2 → 03` 感叹号）。
  即 **序号顺序 ≠ 源图左右顺序**，这是有意为之；改名前务必先开图确认，别凭顺序猜。
- 三张**共用 `1024×1024` 透明画布且不缩放**，保持设计稿里的相对大小。
  若各自紧贴裁切，宽高比不同（0.72 / 0.78 / 0.88）的图标放进同一尺寸 `Image` 会显得大小不一。
- 导入设置已统一为 UI 口径：`Sprite` / `Single` / **无 mipmap** / `alphaIsTransparency` / `Clamp` / `NPOT=None`。
- 核对图：`Captures/art-review/新素材总览-06-图标切分结果.png`（含 24 / 40 px 实机尺寸预览 —— 24 px 下仍可辨认）。

**代码怎么取**（`Assets/Scripts/Unity/Ui/TriggerIconLibrary.cs`）

```csharp
Sprite icon = TriggerIconLibrary.Instance.GetIcon(EffectTrigger.Attack);  // 剑
bool has    = TriggerIconLibrary.Instance.HasIcon(EffectTrigger.Passive); // false
```

图标库资产 = `Assets/Resources/TriggerIconLibrary.asset`，由菜单
`魔法乱斗/整理 · 建触发图标库` 生成（幂等可重跑；同时负责把拼图移入 `_Source/` 并统一导入设置）。

> UI 需自行降级（**不留符号位**），别画成空白方块。

**M17 起这三个符号还要「和文字排在同一行」**（手牌与冷却迷你卡的效果文字 = 一条效果一个符号，

### 3.4 ⚠ 三个必须知道的工程约束

**① 全部字体只有单一字重**

19 个字体的 `usWeightClass` 全是 350 或 400，工程里**没有任何 Bold 字体文件**。因此 UI 上加粗只能靠 **SDF 伪粗体**：

- TMP 的 SDF shader 自带 `_WeightNormal` / `_WeightBold` 两个属性
- 本工程所有 SDF 材质里 `_WeightBold` 已经是 **0.75**（`_WeightNormal: 0`），即默认可用
- 用法：`tmpText.fontStyle = FontStyles.Bold;`
- ⚠ 若以后替换 shader，务必确认新 shader 仍有这两个属性，否则 `Bold` 会变成**无效果**

**② 部分字体缺字 → 已配 fallback**

仓耳渔阳体 W03 与 ZCOOL Addict Italic 02 缺 `α β γ ≤ ≥`，已挂 fallback 到 Noto Sans SC。
**新增字体资产时记得一并挂上**，否则该字体上的缺字会显示成方块。

**③ TMP Essential Resources 已导入（2026-09-16 闭环）**

`Assets/TextMesh Pro/` 已就位，`TMP Settings.asset` 的默认字体也设好了。
⚠ 注意：菜单项 `Window/TextMeshPro/Import TMP Essential Resources` **只弹窗口、不真导入**；
程序化导入要用：
```csharp
AssetDatabase.ImportPackage(
    "Packages/com.unity.textmeshpro/Package Resources/TMP Essential Resources.unitypackage", false);
```
