## 1. 现在的游戏

三个场景、两条路：

```
Home ──► 标准战斗 ─────────────────────────► SampleScene（战斗）
     └─► 自定义战斗 ──► DeckSelect ────────► SampleScene（战斗）
```

| 玩法 | 牌组从哪来 | 谁挑 |
|---|---|---|
| **标准战斗** | 由**本局种子**把整张卡表（44 张）洗一副，双方**顺序各切 8 张** —— 共用一个卡池，所以两边的牌不会重复 | 系统 |
| **自定义战斗** | 玩家在 `DeckSelect` 里挑两边各 8 张 | 玩家 |

**发牌口径（双方一致）**：开局 **6 张**、可换 3 张；**第 2、3 回合各补 1 张**（补牌当拍可换 1）。
牌组是 8 张，分三次到手。唯一实现 = `Core/Cards/DealProfile.cs` 的 `Duel()`，
由 `BattleDriver.BuildSetup` 对场上每个角色覆盖（角色资产上写的不生效）。

**一局结束**：赢 → 「再来一局」（新种子；标准战斗会重新洗一次、再切两副 8 张）；
输 / 平 → 「重试」（**同一颗种子，同一副牌**）/「退出」（回 Home）。

## 4. 验证状态

**已验**

- Unity Console **0 error**（三个程序集都编译过）。
- 三个构建器 **P0 / D1 / M44 都跑过**：`Home.unity`（两枚键）、`DeckSelect.unity`、
  `BattleCanvas.prefab`（只剩设置键）。
- **实跑一局标准战斗**：点「标准战斗」→ 进 `SampleScene`；双方开局各 **6 张**；
  牌组 **8 张**（`n,ad,r,f,q,ae,ap,d`）；对手 = **基础傀儡**（1/1，测试期配置）；换牌面板正常。
- **全卡效果核对（2026-10-30）**：44 张逐张核对「卡面描述 ↔ 卡表 ↔ 引擎结算」，
  每张都作为进攻牌实跑一次五步流水线，另加 26 条行为探针；
  `Tools/RuleSelfTest` 连跑 3000 局 **0 违规**。见
  [全卡效果核对](../../validation/2026-10-30-全卡效果核对.md)。

**没验**

- 自定义战斗**没有实跑**（只验了场景能建、节点齐全）。
- 第 2 / 3 回合的**补牌**没有逐拍观察过（依赖 `DealProfile.Duel` 的区间参数）。
- 胜利 / 失败结算的**重开与退出**没有点过。
- 万局自测**已重跑**（2026-10-30，3000 局 0 违规），但 `BattleSetup.Default()` 仍是旧口径
  （`DefaultPlayer` = 6 张换 3 补牌 / `DefaultMonster` = 8 张不补）——
  是否统一成 `Duel()` 仍未拍板，所以统计数字不代表线上发牌口径。
