# 编辑器内置字体「图集索引失效」排查

> 状态：已修复 · 日期：2026-09-30 · 范围：Unity 编辑器（非工程资产）
> 现象 = 点编辑器画面就刷 `MissingReferenceException: The variable m_AtlasTextures of FontAsset doesn't exist anymore`

## 现象

在编辑器里点击画面（选中对象 / 重绘 Inspector）时，控制台反复弹出：

```
MissingReferenceException: The variable m_AtlasTextures of FontAsset doesn't exist anymore.
You probably need to reassign the m_AtlasTextures variable of the 'FontAsset' script in the inspector.
UnityEngine.Object.get_name ()
UnityEngine.TextCore.Text.MaterialManager.GetFallbackMaterial (FontAsset, Material, Int32)
UnityEngine.TextCore.Text.TextGenerator.SetArraySizes (...)
…
UnityEngine.UIElements.UITKTextHandle.ComputeTextHeight (...)
UnityEngine.GUIUtility:ProcessEvent (Int32, IntPtr, Boolean&)
```

栈是**编辑器 UIElements 在量文字**（`ProcessEvent`），不是游戏逻辑。
`C:\Users\Bruis\AppData\Local\Unity\Editor\Editor.log` 里本次会话共 **4039** 次，
从会话早期一直刷到最后一刻 —— 也就是说**每一次编辑器重绘都在抛**，会连带触发
Console 的 Error Pause。

## 排查路径（关键：先证伪「上次那条」）

1. 先按既有结论查**工程字体 `.asset` 的 `m_AtlasTextures` 引用是不是被清空**
   （那是 2026-09-26 上午修过的那一类，见项目排障笔记）。逐个解析 20 个
   `t:TMP_FontAsset`：**全部 `atlasN = 1`、引用有效、源 TTF 在** → **不是那条**。
2. 换口径：`Resources.FindObjectsOfTypeAll<FontAsset>()`（基类是
   `UnityEngine.TextCore.Text.FontAsset`，编辑器用的字体是**这个基类**、不是 `TMP_FontAsset`）。
   共 25 个实例，其中 **24 个是编辑器内置的 OS 字体资产**
   （`PingFang TC SDF` / `Yu Gothic UI SDF` / `Microsoft YaHei SDF` / `Inter-*` / `GlobalFallback - Win` …，
   共同特征：`m_AtlasPopulationMode = DynamicOS`、`m_SourceFontFile = NULL`）。
3. **命中**：`Yu Gothic UI Bold SDF` 的 `m_AtlasTextures` 有 **2** 个槽位，
   槽 **`[1]` 是一个已销毁的 `Texture2D`**，而 `m_AtlasTextureIndex = 1` —— 索引正好指向它；
   槽 `[0]`（`YUGOTHB Atlas`）是好的。
4. **坐实**（决定性判据）：直接去踩那个槽

   ```csharp
   // o = m_AtlasTextures[1]
   string n = o.name;   // ← 抛出来就是用户看到的那一句，逐字一致
   ```

   实测输出：

   ```
   DEAD slot: Yu Gothic UI Bold SDF idx=1
      >>> UnityEngine.MissingReferenceException: The variable m_AtlasTextures of FontAsset doesn't exist anymore.
   ```

## 根因

编辑器为「粗体 CJK 回退」准备的那份 OS 字体资产（`DynamicOS` + `IsMultiAtlasTexturesEnabled = true`）
在**多图集扩容**路径上留下了悬空索引：`m_AtlasTextureIndex` 指到一张**已被销毁**的图集。
之后任何需要落到该字体的文字（编辑器界面里的中文 / 日文都是这条链）量尺寸时，
`MaterialManager.GetFallbackMaterial` 走到那个槽位取名字 → 抛异常。

⚠ **与工程无关**：出问题的对象不在 `Assets/` 下，是编辑器运行时从系统字体生成的。
按工程字体那条路去找永远找不到。

## 修法

对判定为「有死槽位」的字体资产调 TMP / TextCore 的公开 API 重建数据：

```csharp
fa.ClearFontAssetData(true);   // true = 立刻重建一张新图集
```

（`UnityEngine.TextCore.Text.FontAsset.ClearFontAssetData(Boolean)` 是 **public**；
`UnityEditor.EditorUtility.SetDirty` 对它无用 —— 它没有磁盘资产。）

实测：

| | atlasN | 死槽位 | m_AtlasTextureIndex | 图集 |
|---|---|---|---|---|
| 修前 | 2 | 1 | 1 | `YUGOTHB Atlas`（另一张已销毁） |
| 修后 | 1 | 0 | 0 | `YUGOTHB Atlas` |

## 验证

- 清空 Unity 控制台 → 用 `execute_code` 触发一次编辑器重绘（写中文 / 日文日志文本）
  → 再读控制台：**0 条 error / warning**。
- 全量复扫：25 个 `FontAsset` 实例 + 20 个工程 `TMP_FontAsset`
  的 `m_AtlasTextures` → **坏项 0**。

## 后续事项

- 这类编辑器内置字体资产是**会话内按需生成**的，不在盘上；重启编辑器会重建一份。
  若换了会话又刷同样的异常，**重跑上面那段「枚举 + `ClearFontAssetData(true)`」即可**
  （判据仍是「有没有死槽位」，不要凭猜测清字体）。
- 若频繁复发，可对同一份资产追加 `isMultiAtlasTexturesEnabled = false`
  （把问题从「索引悬空」变成「图集满」）—— **未做**，先观察本次修复的持久性。

## 沉淀的判据

- ⭐⭐ **「已销毁的引用」在 C# 里不是 `null`**：`m_AtlasTextures[i] == null` 为 `true`
  只说明「不能用」，只有 `Object.get_name()` 抛 `MissingReferenceException` 才能区分
  「空引用」与「被销毁」——**探针里要用「故意读一次 `.name` + try/catch」来定性**。
- ⭐ **`"The variable X of Y doesn't exist anymore"` 这句说的是「数组里某个元素被销毁」**，
  不是「整个 X 没了」；照着 `m_AtlasTextures` 逐个槽位查，别去查材质 / 颜色。
- ⭐ **编辑器自己的字体走 `UnityEngine.TextCore.Text.FontAsset` 基类**，
  用 `t:TMP_FontAsset` 搜资产**搜不到它们** —— 那一类必须用
  `Resources.FindObjectsOfTypeAll<FontAsset>()` 才看得见。

### 这次的处置：自动钩子

新增 `Assets/Scripts/Unity/Editor/EditorFontAtlasRepair.cs`：

- 扫 `Resources.FindObjectsOfTypeAll<FontAsset>()`（含编辑器内置的那批）；
- 判据 = `SerializedProperty("m_AtlasTextures")` 里有没有槽「空 / 已销毁」
  （`objectReferenceValue == null` 已覆盖已销毁；再故意读一次 `.name` 兜一层）；
- 修法 = **保持数组长度不变，用第一张有效图集把空槽填满**，填完 `Update()` 回读校验；
- 时机 = `[InitializeOnLoad]` 的 `delayCall` + `playModeStateChanged == ExitingEditMode`
  （抢在「进 Play 后编辑器整体重绘」之前）；
- 另加菜单 **`魔法乱斗/工具 · 修复编辑器字体图集`**（手点一次，带逐条日志）。

### ⚠⚠ 三条弯路（本轮全部实测过，别走）

| 做法 | 结果 |
|---|---|
| **裁掉空槽**（`arraySize--`） | 报错从 `MissingReferenceException` **变成 `IndexOutOfRangeException`** —— TextCore 内部仍按原槽数索引（`MaterialManager.GetFallbackMaterial(..., atlasIndex)`），只换了个名字 |
| **`ClearFontAssetData(true)`** | ⚠ 2026-09-30 那次它有效；**这次它抛异常并半途停下**，把「一好一坏」变成「唯一的槽也空了」—— **越修越坏**。所以新脚本不再用它 |
| **造一张新 `Texture2D` 填进槽** | 对 `HideAndDontSave` 的运行时对象**写不进去**（`ApplyModifiedProperties` 后回读仍是 `NULL`） |

### 「全空」的状态怎么办

**不动它。** 实测 `m_AtlasTextures` 长度 1 / `[0] == null` 时**进 Play 0 报错**
（`DynamicOS` 会按需自建图集）。真出问题就**重启 Unity 编辑器** ——
那份字体是会话内按需生成的，重启即全新重建。
