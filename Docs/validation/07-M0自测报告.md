## 4. 断言覆盖情况

| 类别 | 条数 | 状态 |
|---|---|---|
| 数据类（卡表硬约束） | 6 | ✅ 全绿 |
| 全局不变量（万局每步都查） | 5 | ✅ 全绿 |
| 规则反查（事件流 / 决策结构） | 7 | ✅ 全绿 |
| 40 张卡逐张行为用例 | 1 | ⬜ 待批次 2（需给引擎加 `TestSetup.SetHand(...)` 注入钩子） |

已覆盖的全局不变量：

1. 冷却区中的牌恒满足 `1 ≤ 剩余冷却 ≤ 基础冷却`
2. 手牌恒 ≤ 8 张
3. `Hp ≤ MaxHp` 恒成立
4. 光环指示物数不超过卡面上限；有指示物则必然已激活
5. 回手后光环状态与冷却值被清空

已覆盖的规则反查：

1. 规则 2/7 防御选项全部够挡（**独立重算**可用防御光环预算后校验，不复用引擎的过滤逻辑）
2. 规则 9 进攻开始只减进攻方自己的冷却区
3. 规则 19 有牌时进攻决策不提供「放弃进攻」
4. 推论 P2 连击追加进攻不重复触发冷却 −1
5. 边界「双发未被挡住只扣 1 点」
6. C1 生命上限归零后**下一个事件必然是对局结束**
7. 所有决策请求的选项结构合法（序号连续、无重复、非空、允放弃者必有 Skip）
