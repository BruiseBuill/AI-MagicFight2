# 卡牌 UI 与转场修改记录

工程：`E:/UnityProject/Unity_AI_CardFight2`，Unity 2022.2.15f1c1。通过 Unity MCP 连接、编译、修改预制体与场景、执行受控 UI 检查。

## 修改

- Orb_Energy：初始 `0/1`；玩家进攻开始（含连击追加进攻）恢复 `1/1`；宣告出牌后 `0/1`；对手进攻、防御、终局不恢复。数字变化带轻微缩放反馈。
- 长按放大：仅显示完整牌面，停用旧名称、数值、背景面板；构建器不再生成这些附加内容。
- 冷却牌：仅显示牌面；宽高从 106×149 增至 137.8×193.7（各 +30%）。相邻行间距 10 px。四行总高度 804.8 px，放入原先 621 px 高的独立纵向滚动区域，支持滚轮和细滚动条，避免侵占手牌。冷却值由所在行表示。
- 卡牌转场：按 UID 识别玩家手牌与冷却区之间的变化。出牌先缩小 0.16 秒，再沿弧线飞入冷却区 0.46 秒；回手先放大，再飞到手牌新增的右端位置。多张回手起飞间隔 0.07 秒。目标牌在飞行期间隐藏并禁用射线，完成后恢复；连续快照刷新保持动画，跨区域反向移动和重开清理旧动画。超出冷却滚动视口的牌从最近可见边缘进出。
- 手牌排序：拖拽到手牌区其他位置即可换位；相邻卡平滑让位；不可出牌的牌仍能整理。通过 UID 保持用户排序，快照刷新不会重置；新增/回手牌追加在右侧。出牌仍要求合法选项与出牌判定区。

已保存 `Assets/Scenes/SampleScene.unity`、`Assets/Prefabs/Ui/BattleCanvas.prefab`、`Assets/Prefabs/Ui/CardView_Mini.prefab`。相关构建器同步更新。
