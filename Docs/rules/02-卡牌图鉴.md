# 卡牌图鉴

> 状态：现行 · 核对日期：2026-10-30 · 范围：内置 44 张卡的数值与效果文本。

本表保留当前卡牌规格，并按本次确认规则修正文案；源码对应 [CardLibrary.cs](../../Assets/Scripts/Core/Cards/CardLibrary.cs)。通用规则见 [规则基线](01-规则基线.md)，实际行为差异见 [差异清单](03-规则与实现差异.md)。旧版原始卡表文件已不在仓库中，不再作为必需入口。

α = 进攻效果，β = 防御效果，γ = 特殊效果。冷却列表示基础冷却值；X 表示力量按效果确定。元素用于分类和提示，不参与基础攻防结算。
经典模式使用前 40 张（a–an），普通模式使用全部 44 张。

## 补充说明

- 漩涡不移除任何卡牌；潮汐的冷却完成触发是特殊效果，不是光环。
- 雪崩的双方减速可不执行；决定执行后，双方剩余冷却为 1 的合法目标都受影响。
- 地震按打出前恰有两张手牌判定；地刺按打出前只有自身一张判定。
- “已损失生命”按本局初始生命减去当前生命计算，最低为 0；治疗会减少该值。
- 过载、自燃先恢复生命，再减少上限，最后将当前生命限制在新上限内；该组合效果标注了 `[强制]`。
- 沉重打击不能增加进攻力量；模仿未复制或防御时力量为 1。
- 冰霜核心的虚弱不降低防御力量；火炬的光环复位须受来源牌仍在冷却区的限制。
- `[强制]` 只约束对应效果，不使同一卡牌的其他效果强制执行。

不在当前卡表中的毒刺、击穿、水之形、闪电球、冷冻核心、海啸及旧版火炬规格见 [历史快照](../archive/20261030-文档整理/02-卡牌图鉴.md)。旧卡 ID 可能已复用，不得用旧名称推断当前 ID 的效果。
