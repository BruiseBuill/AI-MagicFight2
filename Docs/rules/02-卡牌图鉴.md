## 元素归属（2026-09-26 新增）

每张卡都标一个**元素**（冰 / 水 / 电 / 火 / 草 / 石 / 诅咒），按**卡名 + 卡面美术的视觉主题**归类
（用户口径）。⚠ **它目前不参与任何规则结算**，唯一的作用是「点击怪物 → 思考框」把预判出的牌
翻译成元素符号（见[点击怪物思考框](../implementation/2026-09-26-点击怪物思考框与七元素图标.md)）。

## 2026-09-29 增量：毒刺（ao）与击穿（ap）

两张新卡由用户下达，美术草稿原先放在 `Assets/Art/CardArt/_Draft/`，本次接入正式目录。

### 毒刺（ao）· 草 · 力量 7 / 冷却 4

| 触发 | 效果 |
|---|---|
| α | 使**被攻击的目标**虚弱 ×2 |

**虚弱**是本作第一类**状态**（此前所有效果都是即时的冷却 / 力量改动）：

| 项 | 口径 |
|---|---|
| 作用对象 | 被攻击的目标（对手）。**不是**双方 —— 卡表里写 `EffectTargetScope.Opponent` |
| 效果 | 该方打出的牌**最终进攻力量 ×50%、之后向上取整**（7→4 · 9→5 · 5→3 · 2→1） |
| 不作用 | **防御力量**（只削进攻） |
| 递减 | 该方**自己的一个进攻半场结束后** −1 层（连击整条链只减 1 层） |
| 叠加 | 可叠加、无上限 |
| 结算阶段 | ① 力量阶段（与其它 α 即时效果同拍）—— 所以「挂上的那一拍」不影响本次攻防 |

### 击穿（ap）· 电 · 力量 3 / 冷却 4

| 触发 | 效果 |
|---|---|
| α | **光环**：使本次打出的法术获得「快速回填」（进冷却区时剩余冷却额外 −1） |
| α | 连击 |

「快速回填光环」是 `AuraKind` 里的第 7 种类型（`QuickRefill`）：它**不是力量加值**
（不参与防御侧「还差几点补值」的预算），也**不是免疫**（走「准备 → 随出牌提交」那条路）。
