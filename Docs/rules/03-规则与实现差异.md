# 规则与实现差异

> 状态：现行 · 更新日期：2026-10-31 · 范围：本次规则落实结果。

基础规则见 [规则基线](01-规则基线.md)。原清单的六项差异已处理；效果交互按用户最新说明采用默认触发，避免逐条确认。

## 落实结果

| 事项 | 当前实现 |
|---|---|
| 放弃追加连击 | 不扣血；整个进攻回合未出牌才扣 1 血。动作按钮从引擎读取实际代价 |
| 人机回合上限 | 完成 40 个完整回合仍未分胜负，判人类玩家失败；支持人类在任一座位 |
| 双人平局 | 进攻或防御选牌时可提出，不消耗行动；从下一完整回合观察四回合，无生命减少则判平 |
| 取消平局观察 | 受到伤害、自损、无法进攻扣血或上限压低当前生命均取消；只降上限不降生命、治疗不取消；可重新提出 |
| 效果执行 | 双发、连击、力量加值、守护、快速回填、光环获取等默认触发，不增加执行/跳过弹窗。加减速、冷却目标选择及有代价的选牌保留可选性 |
| 潮汐目标 | 可选双方冷却区中的合法牌，也可跳过；不是光环 |
| 藤蔓减速 | 第 3 步结算，本次攻防牌尚未进入冷却区，不能成为目标 |
| 牌组来源 | 一局只有一副实体牌堆：标准战斗 = 整张卡表，自定义战斗 = 双方所选 16 张。开局洗一次后双方都从堆顶抽，换掉的牌回堆底；同一张实体牌不可能同时给双方 |
| 发牌入口 | Core 默认对局与 Unity 均使用双方 DealProfile.Duel()，即 6+1+1 |

## 边界约定

- 标注强制的效果必须执行，卡牌固有约束不可跳过。规则上的可选性不要求所有效果弹窗确认；默认有利效果直接执行。
- 光环的获得默认执行，已获得光环的使用仍需主动选择。
- 同一阶段先结算进攻牌、再结算防御牌。**同一卡牌同时带「区域」与「单体」冷却效果时（暴风雪 a：加速 + 区域减速）不再先弹「选择结算顺序」**（2026-10-31）：第一拍把两套目标摆在一起，点冷却槽位（图标）= 先结算区域、点冷却区里的卡片 = 先结算单体；被选中的那条先落地，另一条随后照常问它自己的目标（两条效果都要执行，卡面写的是两条 α）。其余自动效果默认按卡面顺序执行。
- 「选择结算顺序」弹窗已整体移除（2026-10-31 用户口径）：混有无 family 冷却效果的一组（吞食 ad：减速 + 随机查看对方手牌）不再先问「先结算哪个效果」，按卡面书写顺序逐条结算 —— **先减速、再随机查看**；模仿复制吞食同理。44 张里只有吞食（含被复制）走得到这条路径；其余多效果牌要么走「点区域 / 点卡片定先后」的合并拍，要么按结算阶段天然定序。
- AI 对 AI 保留 100 回合保护上限，到限判平。
- 默认角色为 4/4，测试怪物可使用单独生命配置；特殊效果图标的圆圈/感叹号仅为素材差异，不改变 γ 语义。
