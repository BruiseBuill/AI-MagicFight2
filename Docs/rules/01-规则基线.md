# 规则基线

> 状态：现行 · 确认日期：2026-10-30 · 范围：基础对战规则及本次用户确认的项目规则。

本文规定游戏如何运行；本次落实情况见 [规则与实现差异](03-规则与实现差异.md)。具体卡牌见 [卡牌图鉴](02-卡牌图鉴.md)。

## 1. 基本概念

- 每张卡牌称为一个法术，具有力量值、基础冷却值和效果。剩余冷却是对局中的动态数值。
- 每名玩家初始生命值及生命上限均为 4，最多拥有 8 张法术；此数量包含手牌、正在结算的牌和冷却区中的牌。
- 获得全部 8 张后不再常规补牌，依靠冷却完成回手。
- 双方各完成一次进攻回合，称为一个完整回合。连击属于同一个进攻回合。
- 生命值归零立即判负。具体卡牌削减生命上限至 0 时同样判负。

## 2. 发牌与回合开始

1. 双方各获得 6 张法术，可随机替换至多 3 张。
2. 第 2、3 个完整回合开始时，双方各获得 1 张法术；新获得的牌最多替换一次。
3. 每次轮到某方开始进攻时，仅该方冷却区的所有法术剩余冷却减 1；归零立即回手。
4. 防御阶段不进行上述自然冷却；连击追加进攻也不重复自然冷却。

以上替换次数是项目采用的标准值。原版轻松游戏允许双方事先约定放宽，不作为程序默认规则。

## 3. 进攻与防御

- 每次进攻只打出 1 张法术，以结算后的最终进攻力量进行比较。
- 普通防御打出 1 张法术；最终防御力量不低于进攻力量时成功，守护可无视力量差异。
- 只能提交能够完整防御的牌。不能打出力量不足的牌，也不能对双发只提交一张牌。
- 防御方可以不出牌；未防御成功扣 1 点生命值，另按卡面结算额外效果。
- 进攻方可以主动结束进攻。整个进攻回合未打出任何法术时，扣 1 点生命值；无牌可进攻也按此处理。
- 已完成一次进攻后，可以放弃追加连击，不扣生命值；无牌继续连击时直接结束该进攻回合。
- 进攻结束后交换攻防身份；已满足终局条件时不继续结算后续连击。

## 4. 效果与冷却

剑（α）表示进攻效果，盾（β）表示防御效果，圆圈（γ）表示特殊效果，触发时机见卡面文字。

只有标注 `[强制]` 的效果必须执行，未标注的效果可以选择不执行。当前卡表中，写有“可以”的效果和加速、减速类效果均不属于强制效果。可选性不取消卡面写明的对象、条件或限制。

项目交互采用默认触发：双发、连击、力量加值、守护、快速回填、光环获取、条件回手等通常有利的效果直接执行，不逐条弹出确认。加减速、冷却目标选择和有代价的选牌保留选择或跳过；获得光环默认触发，使用光环仍由玩家主动选择。

未限定对象的效果可选择自己或对方的合法目标；写明“你”“对方”或具体区域时，按限定范围选择。

| 术语 | 含义 |
|---|---|
| 加速 / 减速 | 选择自己或对方冷却区的一张牌，使剩余冷却减 1 / 加 1；减速不能超过基础冷却值 |
| 区域加速 / 区域减速 | 选择某一方冷却区的一个剩余冷却数值，使该档所有牌分别加速 / 减速一次 |
| 加速 ×N / 减速 ×N | 将 N 次效果分配给合法目标；可重复选择同一张牌，也可分配给不同牌 |
| 重置冷却 | 将目标的剩余冷却恢复为基础冷却值 |
| 立即冷却完成 | 剩余冷却归零，立即回手 |
| 冷却一张手牌 | 按基础冷却值放入冷却区，不触发该牌的进攻、防御效果；卡面另注明数值时按注明值处理 |

攻防中的法术在本次冷却类效果结算完毕后才进入冷却区，不能成为本次加速、减速等冷却区效果的目标，因此不能用自己的加速加速自己。归零回手的牌不再是后续冷却区效果的合法目标。

## 5. 关键字

| 关键字 | 规则 |
|---|---|
| 进攻力量 +N | 仅增加本次进攻力量，防御时不生效 |
| 连击 | 本次进攻结算后，可再打出一张法术进行一次完整进攻，对方再次防御 |
| 双发 | 防御方须打出两张牌，每张都必须满足防御条件；力量不能相加。不防御仍只扣 1 点生命值 |
| 快速回填 | 作为进攻牌使用后，进入冷却区时剩余冷却额外减 1；防御或被其他效果直接送入冷却时不触发 |
| 守护 | 无视力量差异满足一张防御牌的要求；防御双发仍需两张合格牌 |
| 对方无法防御时 | 指本次未防御成功，包含主动放弃防御 |

## 6. 光环与潮汐

光环在来源牌作为进攻牌使用并进入冷却区后获得，以指示物记录。每枚指示物通常只能使用一次；来源牌回手时，未使用的指示物失效。卡面明确规定恢复指示物时按卡面执行。两条光环对应两个独立指示物。

| 类型 | 使用时机 |
|---|---|
| 进攻力量、连击、快速回填光环 | 自己进攻时，打出法术之前或同时 |
| 防御力量光环 | 自己防御时，打出防御法术之前或同时 |
| 进攻或防御力量光环 | 对应的进攻或防御出牌时机，选择其中一种用途 |
| 免疫光环 | 自己防御时 |

光环只影响本次使用，不永久修改牌面。未实际生效的已准备光环不消耗；连击光环不叠加，且须满足卡面力量阈值。双发防御需要的总补值不得超过投入的防御光环加值。

免疫按最终进攻力量判断；满足条件时免疫整个攻击（包括双发），无需交出防御牌，空手也可使用。

潮汐的“冷却完毕时，使一个法术也立即冷却完毕”是特殊效果，**不是光环**。它在触发时可以收回本进攻回合已经打出并进入冷却区的牌；对方开始进攻前仍属于自己的进攻回合。该说明不提供随时主动触发潮汐的能力。

漩涡不移除卡牌；当前效果为加速及提供快速回填光环。

## 7. 单次进攻结算顺序

1. 结算进攻力量效果、已用光环、双发，确定攻击。
2. 结算防御力量效果、守护或免疫，判定防御。
3. 结算加速、减速、其他冷却变化及查看手牌等效果。
4. 本次攻防法术进入冷却区，结算快速回填。
5. 激活本次获得的光环。
6. 结算连击；继续时从第 1 步开始，不重复回合开始处理。

一张法术有多个同优先级冷却效果时，由使用者选择顺序，例如先加速或先区域加速；自动效果默认按卡面顺序处理。同一阶段跨卡按进攻牌在先、防御牌在后结算。特殊效果按卡面触发条件插入。

## 8. 胜负与模式

| 模式 | 结束条件 |
|---|---|
| 所有模式 | 一方生命归零，另一方获胜 |
| 玩家对 AI | 最多 40 个完整回合；第 40 回合结算后仍未分胜负，玩家失败 |
| 双人游戏 | 一方提出平局后，若双方在后续四个完整回合内均未造成伤害，则自动平局 |

双人平局从提议后的下一个完整回合开始计时。任一方实际生命减少（包括自损、无法进攻扣血、削减上限导致的生命截断），取消本次观察；之后可以重新提出。仅降低上限但不减少生命、治疗均不取消。连续四个完整回合均无生命减少，则平局。

AI 对 AI 的运行保护上限属于实现配置，不代替上述规则。
