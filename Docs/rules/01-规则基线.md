## 0. 通用原则

| 原则 | 说明 |
|---|---|
| **效果可选性** | 只有单体加速、单体减速、区域加速、区域减速允许选择跳过；回血、快速回填、光环获取及其他效果自动执行。雪崩（an）的区域减速同样强制执行。 |
| **目标指定** | **未写明对象**的效果可以指定任意合法目标；写明了对象的（"对方"= 攻击目标、"你"= 使用者）不可更改。 |
| **卡面数字** | 第 1 个数字 = **力量值**，第 2 个数字 = **基础冷却值**。 |
| **效果符号** | α = 进攻时效果（剑）· β = 防御时效果（盾）· γ = 特殊效果（圆圈，时机见卡面文字）。 |
| **同优先级** | 一张牌若有两个**同优先级**效果，由玩家自行指定结算顺序。 |

## 1. 资源与胜负

- 生命来自角色配置；当前默认玩家/怪物初始 **4 点生命值**，生命上限 4。
- “已损失生命”统一为 `Max(0, 本局初始生命 - 当前生命)`；回血会降低该数值，削减生命上限不改变本局初始生命基准。
- 手牌上限 **8 张**。达到 8 张后不再获得新牌，回手完全依赖冷却。
- **生命值归零 → 立即判负。**
- **生命上限归零 → 即刻死亡**（上限可被效果削到 0）。
- 默认发牌总数 = 初始 6 + 第 2、3 回合各 1 = 8 张（漩涡永久移出后为 7 张）。
- 每名角色拥有独立有限牌堆，由角色卡池创建，每种卡最多一张；双方可以抽到同名牌。抽牌消耗本方剩余牌堆，换掉的牌返回本方牌堆；牌堆耗尽不再抽牌或提供换牌决策。
- 角色配置最少卡牌数，人类玩家默认 8；保存卡池和创建对局都必须满足该限制。卡池数量与开局手牌数、手牌容量是不同概念。

## 2. 回合结构

```
回合 N：
  ├─ 半场 A：玩家 1 进攻 → 玩家 2 防御
  └─ 半场 B：玩家 2 进攻 → 玩家 1 防御

第 2、3 回合开始时：双方各获得 1 张法术（各最多替换 1 次）
```

- 双方各进攻一次 = **1 回合**。
- **每场战斗最多 40 个完整回合**（字段 `BattleState.TurnLimit`，数值可配，但**必须存在上限**）。
  第 40 回合结算完仍未分胜负 → **判 seat 0（人类玩家）失败**，结算原因「回合上限」。
  - 连击的追加进攻**不额外计回合**（与推论 P2 同口径：每个半场只结算一次）。
  - ⚠ **实现状态：规则已由用户确认（2026-09-25），引擎尚未落地**（见 [冒险模式实施规格](../design/冒险模式实施规格.md) §4）。
    背景：内核原本没有回合上限，个别种子会走出双方永远挡得住的"冷战"局（`seed 20261601` 走到 3158 回合仍在继续）。
    落地后**必须重跑万局回归**并按新结果更新基线。
- **进攻开始时**（该半场开始的那一刻），**进攻方自己**的冷却区全体剩余冷却 **−1**；归 0 的牌立即回手。
- 防御方在自己的防御阶段**不做**冷却结算。
- **连击的追加进攻不重复触发冷却 −1**（每个半场只结算一次）。

## 3. 单次进攻流程

```
① 进攻方从手牌选 1 张打出（每次进攻只能打 1 张）
       ↓
② 防御方二选一：
     a) 打出一张 力量 ≥ 攻击方最终力量 的手牌（或守护牌）→ 防御成功
     b) 放弃防御 → 掉 1 点生命值
       ↓
   若防御方手上没有任何能挡住的牌 → 只能走 b)
```

**硬性约束**

- 防御方**不允许打出挡不住的牌**（引擎在生成选项时即过滤，AI 与 UI 都拿不到非法选项）。
- 防御方**可以主动放弃防御**。
- 进攻方**有牌时不可以主动放弃进攻**（跳过进攻）——只有在**手上完全没牌**时才构成"无法攻击"。
- 进攻方无法攻击 → 掉 1 点生命值，该半场结束。

## 4. 冷却系统

冷却只有以下**五条通路**，别无其它增减方式（雪崩那条强制区域减速属于「区域减速」这一条，只是**不可选**，所以单开一行说清）：

| 通路 | 效果 |
|---|---|
| 进攻开始结算 | 进攻方自己的冷却区全体 **−1**；归 0 立即回手 |
| 加速 | 目标牌剩余冷却 **−1**（可指定己方或对方的冷却区中的牌） |
| 减速 | 目标牌剩余冷却 **+1**，**上限 = 该牌的基础冷却值** |
| 区域加速 / 区域减速 | 选定**某一方冷却区**中**某个剩余冷却数值 k**，把该区所有剩余冷却 = k 的牌全体 **±1** |
| 雪崩的强制区域减速 | **双方**冷却区中剩余冷却 = 1 的牌全体 **+1** —— k 与「双方」都写死在卡上，**玩家没有任何选择**（2026-09-25） |
| 重置冷却 / 立即冷却完成 | 重置：剩余冷却恢复为**基础冷却值**；立即冷却完成：剩余冷却**归 0**，立即回手 |

**注意**

- 使用后的牌**立即**进入冷却区，剩余冷却 = 基础冷却值。
- **正在攻防的两张牌，在结算全部完成前不进入冷却区**，因此不受任何冷却类效果影响。
- **加速 ×N**：可以给同一张牌加速 N 次，也可以给 N 张牌各加速一次（减速同理）。
- **地震（i）的减速带进门条件**（2026-09-23）：只有当它是你**最后两张手牌**之一时
  （= 打出它之后手上只剩 1 张）才结算减速；条件不满足时**整条效果无事发生** ——
  不弹选择、不消耗任何东西。
- 按基础冷却进入冷却区的手牌（磁暴/电弧/充能/蘑菇/雷云造成的）**不触发该牌自身的攻防效果**。

## 5. 关键字

| 关键字 | 语义 |
|---|---|
| 进攻力量 +? | 本次进攻的进攻力量 **+?**（仅进攻时生效） |
| **连击** | 本次进攻结算完后，进攻方**再进攻一次**（再打出 1 张），对手需**再次防御**。可连锁。 |
| **双发** | 对方必须**交出两张牌**才能挡住；两张牌的力量都需 ≥ 攻击力量。**若对方选择不防，也只掉 1 点生命值。** |
| **快速回填** | 本牌进入冷却区时，剩余冷却**额外 −1** |
| **守护** | **无视力量差异，必定挡住**（只挡 1 次攻击，见 §7） |
| 重置冷却 | 目标剩余冷却恢复为基础冷却值 |
| 立即冷却完成 | 目标剩余冷却归 0，立即回手 |
| 对方无法防御时 | 指对方**未防御成功**——对方主动放弃、或对方手上没有能挡住的牌，两者均算 |

## 6. 光环规范

光环是**一次性辅助技能**，遵守以下全部条款：

### 6.1 获得

- 带光环的牌**作为进攻牌打出**时获得（所有光环均标注 α，无一例外）。
- 该牌**进入冷却区之后**光环才真正生效（结算第 ⑤ 步"光环激活"）。
- 因此**免疫光环只可能作用于之后的防御**——本张牌当次用不上自己的免疫。
- **⚠ 2026-09-20 实现修正（M22）**：判据是**光环效果自己的触发符号**，不是「一律点亮」——
  - 本牌作为**进攻牌**打出 → 只有 **α** 光环被点亮；
  - 本牌作为**防御牌**打出 → 只有 **β** 光环被点亮（本批没有 β 光环，所以一条都不亮）。
  - 2026-09-18 的实现一度写成「光环与该牌是攻是防无关」（防御牌也点亮），**与本节冲突，已作废**。
  - 同一张牌上的光环**必须同符号**（`CardLibrary.ValidateAuraTriggers` 会断言）——
    指示物是按「同型的一次性资源」建模的，混符号会分不清点亮的是哪一枚。

### 6.2 使用

- 该牌**位于冷却区期间**，玩家可在满足场合限制时消耗**一枚指示物**。
- 进攻光环在选定本次攻击牌后、效果结算前选择；防御光环在防御出牌前选择。
- 加成**仅作用于当时正在打出的那一张牌**，**单次有效**，**不永久改造牌面**。
- **例外：沉重打击（h）**。卡面写着「此法术的进攻力量不能增加」—— 进攻侧的**任何**加值
  （进攻力量光环、力量增益算子）对它一律无效，引擎按卡面原力量结算；
  ⚠ 由于是**显示与规则同一口径**的事（2026-09-25），手牌上的「力量预览」也必须跳过它 ——
  否则会出现「卡面显示 9、实际打出 7」。防御侧不受影响（该规则只管进攻力量）。
- 使用时**不强制**——可以选择不用。
- 玩家将当前可用的 HudBuff 图标拖到自己的手牌区才消耗；防御加值光环也必须逐枚主动选择，不再自动投入。
- 防御加值只计入本次已消耗预算；双发时两张防御牌所需补值合计不得超过该预算。
- 单击不能进攻或防御，必须拖动手牌到出牌判定区；换牌及效果选目标仍可点击。
- HudBuff 左边显示玩家、右边显示敌人。每枚指示物一个图标，同类型不合并；长按查看，消耗或失效即移除。

### 6.3 场合限制

| 光环类型 | 可用场合 |
|---|---|
| 进攻力量 +N（含"获得连击"） | **仅进攻时** |
| 防御力量 +N | **仅防御时** |
| 进攻 +3 **或** 防御 +3 | 进攻或防御皆可，使用时选择 |
| 免疫力量 ≥6 / ≤3 的攻击 | **仅防御时** |

### 6.4 双光环与失效

- 卡面写了两条**相同**光环 = **两个独立指示物**：可以一次用掉两个，也可以分两次各用一个。
- 该牌**冷却完毕回手**时，未使用的指示物**全部作废**。

### 6.5 免疫光环的判定（已确认）

- **免疫会直接免疫掉整个攻击，包括整个双发**（不是逐张判定）。
- 判定依据为攻击方的**最终攻击力量**是否落入免疫区间（≥6 或 ≤3）。
- **⚠ 2026-09-18 规则改动（用户口径）**：消耗免疫光环 = **整个攻击被免疫，且不需要再打出一张防御牌**。
  - 它走的是**独立的一拍**（`ChooseAuraUse`，由 HudBuff 里的光环图标拖动触发），
    此时防御方**还没进入防御决策**；
  - 一旦消耗，引擎**直接判定防御成功**并跳过这一拍的防御决策 —— 本来要交的那张牌留在手上；
  - 旧推论 **P1「免疫后仍须交一张防御牌」作废**（见 §10）；
  - 防御方<b>选择不消耗</b>时，照常进入防御决策（出牌 / 放弃）。
- 免疫光环**不再要求「防御方手上还有牌」** —— 它自己就能解决整个攻击。

## 7. 边界判定（已逐条确认）

| 场景 | 判定 |
|---|---|
| 双发 × 防御方只有 1 张够挡的牌 | **不能部分防御**。要么交两张都够的牌，要么**一张都不交**、掉 1 点血 |
| 双发 × 对方放弃防御 | 只掉 **1 点**生命值 |
| 守护 × 双发 | 守护**只挡 1 次**攻击。双发仍需两张牌都满足 |
| 免疫光环 × 双发 | **整个双发被免疫**（防御成功） |
| 进攻方有牌却想放弃进攻 | 不允许 |
| 防御方有能挡的牌却想放弃 | **允许**，掉 1 点血 |
| "对方无法防御时"的判定 | 凡未防御成功均算（含对方主动放弃） |

## 8. 结算顺序（单次进攻内）

```
① 效果 / 光环带来的进攻力量增加 → 双发 → 攻击
② 防御力增加（含守护） → 防御
   └ 防御方的「β 防御时力量 +A」在这里生效：**防御力量 = 该牌自己的力量 + β 加值**，
     与进攻力量不是同一个数（潮汐 / 地动波：7 也能挡 8）。
     ⚠ 2026-09-20（M22）才接上 —— 此前这个算子没有任何结算点，是静默失效的。
③ 加速 / 减速 / 其他冷却改动 / 查看对方手牌并使其进入冷却
④ 本次的进攻牌与防御牌进入冷却区 → 快速回填
⑤ 光环激活（获得指示物）
⑥ 连击（追加一次完整进攻，从 ① 重新开始）
```

## 9. 生命与生命上限

- 削上限按常规理解：**先结算回血 → 再削减上限 → 最后 `Hp = min(Hp, MaxHp)`**。
  - 例：2/4 血吃「恢复 1 点、上限 −1」→ 先回到 3 → 上限变 3 → 结果 3/3。
- **上限可以减到 0，归零即刻死亡。**
- `[强制]` 标记的效果（过载、自燃的"恢复 1 点生命、减少 1 点生命上限"）**必须执行**，不可无视。
