## 1. 三条铁律（改任何代码前先满足）

1. `Assets/Scripts/Core/` **不得出现 `using UnityEngine`**（asmdef `noEngineReferences` 编译期强制）。
2. **依赖只能向下**：表现层只做「读快照 + 订阅事件 + 提交决策」，不得反向调用引擎。
3. **规则约束只收敛在引擎一处**：非法选项在生成 `Options` 时就被过滤 —— 界面与 AI 都不重复判断。

另外两条与「界面怎么长」直接相关：
4. **要长期存在的节点一律由构建器生成**（手摆在 Prefab 里的活不过一次重跑）。
5. **提示类颜色一律不在代码里**（只写在 Prefab 的 `Image.color` 上，运行时只切 active / enabled）。

## 4. 已知遗留 / 未做

- ⭐ **内核没有「僵局 / 平局」判定**（M36 发现，已证实与 M36 / M37 改动无关）：seed **20261601**
  会走出一条双方永远挡得住的「冷战」局（3158 回合仍在继续，被自测的 20000 决策护栏拦下）。
  规则基线只有「生命归零判负 / 上限归零即刻死亡」，没有回合上限。
  **要根治需要补一条「回合上限 → 平局」规则**，等用户定。
  ⚠ **跑回归时避开这个种子**：它落在「种子基 20260916 的第 685 局」——
  所以 `dotnet run -- 3000 20260916` 会红，而 `dotnet run -- 10000 20261700` 全绿。
  换了卡表 / 引擎后这个种子会**漂移**，报「决策轮次超过 20000」时先怀疑它、别先怀疑自己的改动。
- **M10 设置面板没做**：顶栏齿轮现在是「重开一局」（M28 口径）；`LogPanel` 与 `SetLogVisible` /
  `ToggleLog` 都还在，但**暂时没有入口**。
- **真机端到端提交链路未跑**（见上表）。
- 进 Play 时会报 5 条 `MissingReferenceException: Texture2D destroyed`（进 Play 即报，
  早于对局逻辑；M36 代码不创建 / 销毁纹理）。疑似与 M11 重建后立刻进 Play 的域重载有关。
  ⚠ 它会触发控制台 Error Pause，把 Play 挂起（`isPaused=True`、frame 不涨），别误判成游戏卡死。
- **M35 的「进攻牌与防御牌同帧起飞」只有逻辑 + 定点证据，没有视觉同框截图**：
  飞行只有 0.62 s，一次截图往返比它长，采样总差一拍。逻辑侧的证据是
  「引擎第 ④ 步同批入冷却」+ 「两侧 `flights` 都能建立（`seat=0`与`seat=1`各验过一次）」。
- **`Assets/Prefabs/Ui/CardView_Hand.prefab` 里有用户的手改**（卡名文本 / 三处字体加粗 /
  名称背景框尺寸与透明度，2026-09-25）：**不要跑 `UiKitBuilder` 那批菜单**（会重写该 Prefab），
  真要重跑先备份这个文件。
- `implementation/` 里 M25 之前的**历史文档**保留原样，别照它们改代码（见[索引](implementation/README.md) 第 2 节）。
- 场景：`Assets/Scenes/SampleScene.unity` 挂 `Assets/Prefabs/Ui/BattleCanvas.prefab`；
  **改 UI 后跑构建菜单不会保存场景**，要另调一次场景保存。
