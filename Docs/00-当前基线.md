# 当前基线

> 状态：现行 · 核对日期：2026-10-31 · 范围：代码、配置与本次定向规则检查。

## 产品范围

| 项目 | 当前实现 |
|---|---|
| 场景 | `Home` → 标准战斗 → `SampleScene`；自定义战斗经 `DeckSelect` 选牌后进入战斗 |
| 标准战斗 | 一局只有一副实体牌堆（默认 44 张），开局洗一次；双方都从堆顶抽，换掉的牌回堆底，因此不可能拿到同一张 |
| 自定义战斗 | 双方从同一卡表各选 8 张，16 张组成这一局的实体牌堆；同一方与双方之间都不能重复，另一方已选的牌不可再加入 |
| 卡池 | 默认 44 张；经典模式使用前 40 张（a–an），排除 ao–ar |
| 发牌 | Unity 的 `BattleDriver.BuildSetup` 为双方使用 `DealProfile.Duel()`：6 张开局、第 2、3 回合各从共用牌堆顶补 1 张；**换牌 = 把牌向上拖进换牌区**，已标记的牌一起拖入即整批换掉（开局至多 3 张、补牌当拍 1 张） |
| 控制方式 | 玩家对 AI、AI 对 AI、同机双人热座；未实现网络对战 |
| AI | 简单档按当前力量出牌，不使用光环、不换牌；标准档使用启发式与怪物策略 |
| 设置 | `GameSettings` 通过 PlayerPrefs 保存，开局读取；自定义牌组由 `BattleLaunch` 跨场景保存，不落盘 |
| 已移除功能 | 冒险、地图、商店、强化及对应存档；历史见 [删减归档](archive/20261028-删减冒险/README.md) |

## 规则与代码的边界

正式玩法见 [规则基线](rules/01-规则基线.md)，代码差异集中在 [规则与实现差异](rules/03-规则与实现差异.md)。

- 人机 40 回合判玩家失败；双人可提出平局并观察后续四个完整回合，实际生命减少即取消；全 AI 为 100 回合保护上限。
- 主动放弃追加连击不扣血；整个进攻回合未出牌才扣 1 血。
- 默认有利效果自动执行，不逐条确认；加减速、冷却目标和有代价的选牌保留选择。
- `DefaultPlayer.asset` 与 `DefaultMonster.asset` 均为 4/4；`BattleCanvas.prefab` 的 `_monsterConfig` 当前为空。部分测试怪物由 `MonsterBuilder.TestHp = 1` 生成，不能据此断言所有对局都是 1 血怪物。
- `BattleSetup.Default()` 与 Unity 对战均使用双方 `DealProfile.Duel()`；特殊角色仍可显式配置其他发牌方案。
- 热座的角色美术和结算称谓仍有适配限制，见 [框架变更记录](implementation/2026-10-30-对局框架可替换与设置面板.md)。
